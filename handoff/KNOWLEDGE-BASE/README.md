## 2. 書き方の作法

### 2-1. 形式は自由
- 箇条書きでも、雑談調でも、専門用語入りでも何でもOK
- 川崎さんの**音声を文字起こししたもの**でも全然OK
- 写真URLを貼るだけでも価値ある

### 2-2. 「これ言ってもいい？」と迷ったらメモを残す
- 末尾に `⚠未確認：` で書き始めると、エージェントEが法務チェックに通す
- 例：「⚠未確認：ジアミンフリーでもアレルギー出る人はいる、と書いてOK？」

### 2-3. エージェントが使えるよう構造化
- 各ファイルの **H2見出し** がエージェントの検索キー
- H2はなるべく具体的な質問形（「白髪が突然増えるのはなぜ？」「カラー直後のシャンプーはいつから？」）
- 答えはH2の下に箇条書きでOK

## 3. エージェントによる参照方法

A・B・C は投稿/返信を生成する前に、必ずこのナレッジベースを読む。
プロンプトに以下を埋め込む：

```
次の投稿テーマ「{テーマ}」について、
handoff/KNOWLEDGE-BASE/ の関連ファイルから根拠を引いて投稿を組み立てよ。
根拠が見つからない場合は、その旨を明示し推測しない。
```

これにより、エージェントの出力は**ナレッジベースに紐づいた発信**になる。  
ナレッジベースに無いことを勝手に作らない＝薬機法・誤情報リスクを下げる。
