# エージェントJ：オペレーション（川崎さんの稼働管理）

作成日: 2026-06-10
位置づけ: 10番目のエージェント
役割: カラーリスト川崎さんの稼働を守る・拡大判断のサポート

---

## 1. なぜ必要か

サブスク5,000名を目指す上で、ボトルネックは**川崎さん1人のキャパ**。  
無理させると品質が落ちる・離脱する・健康を損なう。  
J は「品質と人を守りながらスケールする」ための司令塔。

---

## 2. 役割

- 川崎さんの日次稼働を計測（相談件数・返信時間）
- 過負荷シグナルを検知してユーザーへ警告
- カラーリスト2人目雇用タイミングを提案
- 営業時間外の自動応答ルール管理

---

## 3. 計測指標

| 指標 | 説明 | 警告閾値 |
|---|---|---|
| 日次相談件数 | LINE着信→川崎さん返信の数 | 25件超で警告 |
| 平均応答時間 | 相談→返信の中央値 | 4時間超で警告 |
| 営業時間内処理率 | 営業時間内に応答完了した割合 | 70%下回りで警告 |
| 川崎さんの送信文字数（疲労指標） | 1日あたり累計 | 5,000字超で警告 |
| 連続稼働日数 | 休みなく対応した日数 | 6日連続で休み推奨 |

---

## 4. 起動条件

| トリガー | 内容 |
|---|---|
| 毎朝の「おはよう」 | 前日の稼働サマリーをユーザーへ |
| 営業時間内の警告閾値到達 | 即時、ユーザーへ通知 |
| 連続稼働6日 | 翌日休暇推奨カード |
| 月末 | 月次稼働レポート＋スケール判断材料 |

---

## 5. スケール判断のロジック

川崎さん1人で持てる顧客数の上限を**150名**と仮定（仮、運用で校正）。

```
現サブスク数 / 150 ≥ 0.8 → カラーリスト2人目を募集開始
現サブスク数 / 150 ≥ 1.0 → 緊急、新規受付一時停止
```

2人目採用は、雇用形態・報酬体系・教育期間を考慮し**3ヶ月前から準備**。

---

## 6. 営業時間外の自動応答ルール

J は時間帯別に Bot の振る舞いを管理：

| 時間帯 | 対応 |
|---|---|
| 平日 9:00-19:00 | 川崎さんが個別対応（Bot補助OK） |
| 平日 19:00-22:00 | Bot が「翌営業日返信」案内、緊急キーワードのみエージェントBが優先カード化 |
| 平日 22:00-翌9:00 | Bot のみ、エージェントBはキューに溜める |
| 土日祝 | Bot のみ、川崎さんは月1回チェック |

緊急キーワード例：
- 「頭皮 痛い」「染料 入った 目」「染めたら 腫れた」「アレルギー 出た」「血」
→ これらが顧客LINEに来たら**即時 H・B同時起動 + ユーザーへFlex警告**

---

## 7. 川崎さんとの認識合わせ

J は週1回、川崎さんに以下を確認：
- 直近1週間の疲労度（1-5）
- 続けたい相談・断りたい相談の傾向
- システムへの要望（テンプレ追加・ショートカット）

このフィードバックを基にエージェントD（コード）へ改善Issueを起票。

---

## 8. アウトプット例

```
[J-Ops] 川崎さん稼働レポート 2026-06-MM

昨日の実績:
- 相談件数: 18件（前週平均 14件、+29%）
- 平均応答時間: 2時間40分（健全）
- 営業時間外着信: 3件（朝対応キューへ）

直近7日トレンド:
- 件数+19%、応答時間+15分
- 稼働日数: 連続5日（明日休み推奨）

ユーザーへの提案:
- 明日6/15は休み推奨（連続6日突入回避）
- 週末の営業時間外応答数が増加 → Bot自動応答テンプレ追加を検討

承認 / 修正 / 却下
```

---

## 9. KPI

- 川崎さんの平均応答時間（目標：2時間以内）
- 営業時間内処理率（目標：80%以上）
- 川崎さんの連続稼働日数（5日以内に休み）
- 顧客あたりの月次平均相談回数（目標：1.5〜2.5回）
