# エージェントG：SNSインテリジェンス（追加仕様）

作成日: 2026-06-10
位置づけ: 6エージェント体制 → **7エージェント体制に拡張**
役割: SNSマーケティングのリアルタイム情報収集・分析。エージェントA（投稿生成）の上流に立つ。

---

## 1. 役割

- 各プラットフォーム（Instagram Reels / note / Threads）の**最新アルゴリズム動向**を常時把握
- 伸びている投稿パターン・時間帯・構成・ハッシュタグ・ツリー構造を分析
- エージェントAに「今この瞬間、何を、どう、いつ出すべきか」を渡す
- 競合（coloris.shop, 美容室系インフルエンサー, セルフカラー系アカウント）の動きを定点観測

---

## 2. 起動条件

| トリガー | 内容 |
|---|---|
| 毎日朝の「おはよう」 | 直近24時間の動向サマリーをAに渡す |
| 毎週月曜朝 | 週次トレンドレポートをユーザーへFlex送信 |
| 緊急トレンド検知 | バズワード/競合の急成長を検知したら即座にAへ追加タスク |

---

## 3. 情報源（合法かつ持続可能なものに限る）

### 3-1. プラットフォーム公式情報
- Instagram Creators 公式ブログ・ニュースレター
- Meta for Business アップデート
- note 公式ヘルプ・運営ブログ
- Threads/Meta の機能リリースノート

### 3-2. SNSマーケ専門メディア（RSS/サイトクロール）
- ferret-plus.com
- SocialMediaLab
- SNS Marketing Blog（複数）
- ホットリンク社の調査記事
- HubSpot Japan ブログ

### 3-3. 国内外マーケターのコンテンツ
- 主要マーケターの note / X（Threads）アカウント（巡回リスト）
- Marketing Brew、Buffer Blog、Later Blog（海外）

### 3-4. 競合・類似アカウントの定点観測
- coloris.shop の Instagram / Threads / note
- セルフカラー系アカウント上位10件
- 美容室系インフルエンサー上位20件
- 観測項目：投稿頻度・時間帯・形式・反応数・伸び方

### 3-5. 禁止事項
- 各プラットフォームのTOS（利用規約）違反となるスクレイピングはしない
- ログイン情報を使う自動化はしない
- 公開ページの取得は robots.txt と rate limit を尊重

## 4. アウトプット仕様

### 4-1. 朝の「動向サマリー」（A向け、内部メモ扱い）

```markdown
## G日次レポート 2026-06-MM

### Instagram Reels
- 推奨投稿時間帯（過去7日伸び実績）：19:30-21:00 / 12:00-12:45
- 伸びている構成：「結論→理由→具体例→質問CTA」
- ハッシュタグ動向：#セルフカラー が前週比+18%、#リタッチ が+22%
- 警告：3秒以内の冒頭テキストが必須化（離脱が前週比+15%）

### Threads
- 推奨投稿頻度：日3〜5回（ツリー含む）
- 伸び実績の構造：1投目で問題提起 → 2投目で根拠 → 3投目で結論
- 反応の出やすい時間帯：7:30-8:30 / 21:00-22:30
- 競合動向：coloris.shop は週5本ペース、エンゲ平均◯◯

### note
- 推奨更新頻度：週1本以上
- 伸びている記事構成：①引きの強いタイトル ②冒頭3行で結論 ③具体事例 ④まとめ
- タグ動向：#美容 #ヘアケア が直近で検索流入の主軸

### 競合の動き
- coloris.shop：週次キャンペーン投稿を金曜18時に固定
- 主要美容室インフル：白髪関連で2026-06に投稿数が前年同月+40%
```

### 4-2. 週次トレンドレポート（ユーザー向け、Flex送信）

毎週月曜朝にFlex Messageで届く：

```
🔷 G週次トレンド 2026-W24

📈 今週伸びたパターン
・Reels「悩み→3秒で解決提示」型
・Threadsの夜帯ツリー
・noteの「失敗談から学ぶ」型

🎯 来週Aに反映する変更
・Reels冒頭3秒の見直し
・Threadsツリーを週3本に増加
・noteは「相談実例」シリーズ化

⚠ 注意
・Reelsで「絶対」「100%」表現の reach 制限が強まった
```

## 5. エージェントAとの連携

A は G の朝レポートを必ず入力とする：

```
A入力 = {ベースの差別化7軸} + {Gの当日トレンド指示}
A出力 = {プラットフォーム別の投稿案} + {採用したG指示の引用}
```

A の Issue 本文に「G指示の反映内容」を必ず1ブロック書く（後日の振り返り用）。

---

## 6. 効果検証ループ

```
G が時間帯/構成を推奨
  ↓
A がそれに従って投稿生成
  ↓
ユーザー承認 → 投稿
  ↓
F（分析エージェント）が48時間後にエンゲ実績を取得
  ↓
G に「推奨が当たったか」をフィードバック
  ↓
G の推奨ロジックを更新
```

## 8. 段階的に始める

### Phase 1（今すぐ）
- 観測対象URL/RSSのリスト作成（手動キュレーション、10〜15本）
- 朝の「おはよう」時に Claude本体がそのリストを巡回して要約 → A に渡す
- 専用のWorker処理はまだ作らず、まずプロンプト運用で価値を確認

### Phase 2（運用開始2週間後）
- D1にトレンド観測ログを溜め始める（手動キュレーションを継続）
- 週次レポートのFlex送信を自動化

### Phase 3（運用開始1ヶ月後）
- RSS取得・要約をWorker内で自動化
- FとGの双方向フィードバックループを稼働
