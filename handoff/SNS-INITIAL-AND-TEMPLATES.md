# SNS テンプレート＆初期バックログ

作成日: 2026-06-10
対象プラットフォーム: Instagram Reels / note / Threads
位置づけ: エージェントA・G運用開始までの「初期燃料」と継続運用の雛形

---

## 0. 全体方針

- **初期3日分は人力（私=Claude）で作成**、4日目以降は G→A の自動運用へ移行
- **テンプレートは継続資産**として永続維持
- **note と Threads は API 連携で完全自動投稿**を目指す（Reelsは撮影が必要なので半自動）

---

## 1. フォーマット雛形

### 1-1. Instagram Reels（縦型動画 15〜60秒）

```
[フック 0:00-0:03] ← ここで離脱を防ぐ
  → 結論先出し or 共感パンチライン
  → テキストオーバーレイ大きく1〜2行

[ボディ 0:03-0:45]
  → 理由 → 具体例 → ビフォーアフター
  → カット切替は2〜4秒に1回（離脱対策）

[CTA 0:45-0:60]
  → 「保存してね／LINE相談はプロフから」
  → アカウントロゴ・ハンドル表示

【投稿時の固定項目】
キャプション：80〜120字（最初の1行で要旨）
ハッシュタグ：8〜12個（大中小ミックス）
カバー画像：縦長、文字サイズ大、ブランドカラー統一
```

### 1-2. note（長文記事 1,500〜3,000字）

```
タイトル：「数字＋ベネフィット＋意外性」で30字前後
  例：「白髪を毎月980円で。美容室に行かない、でも染め続ける方法」

リード（冒頭3行）
  → 読者の悩み代弁
  → 記事で得られるものを明示
  → 「読み終える頃には◯◯が分かります」

本文構成（H2見出し3〜5個）
  ① なぜ今この話か（背景）
  ② 結論（最も伝えたい1つ）
  ③ なぜそう言えるのか（根拠・データ・事例）
  ④ よくある反論への回答
  ⑤ 行動への接続（LINE登録/サービス紹介）

クロージング
  → 一文で要約
  → CTA（LINE登録URL）
  → 「次回はこういう話をします」予告

タグ：3〜5個（#美容 #ヘアケア #白髪 等）
ヘッダー画像：横長、タイトル文字入り、ブランド色
```

### 1-3. Threads（短文/ツリー 500字以内×複数）

```
【単発投稿】
1〜3行で完結、感情の波を1つ
例：
「白髪、減らないし増えるしで、もう諦めかけてた人へ。
減らなくていい。増えるたびに、その場所だけ"見えないように"する。
それでQOLは戻ります。」

【ツリー投稿】（3〜5投稿）
1投目：問題提起（引きを作る）
2投目：根拠（なぜか）
3投目：具体例（誰かの実話）
4投目：結論（言いたいこと）
5投目：CTA（LINEへ）

ツリー投稿の鉄則：
- 各投稿で「次が気になる」を作る
- 投稿間隔は30秒〜2分で連続投下
- 最後の投稿だけリンク（早すぎると伸びない）
```

## 2. 初期3日分バックログ

### Day 1（リタッチ専用×LINE個別相談）

#### Reels D1
```
【フック】
「美容室で全頭染め、もう疲れた人へ。」（テキスト大）

【ボディ】
- BGM：チル系インストゥルメンタル
- カット1（0:03-0:10）：分け目アップ→白髪が見える映像
- テキスト：「気になるのは"ここだけ"なのに」
- カット2（0:10-0:25）：全頭染めの薬剤画像→×印
- テキスト：「毎回全部染める必要、ある？」
- カット3（0:25-0:45）：FOLLOWのLINE画面→相談中の様子
- テキスト：「分け目だけ。生え際だけ。リタッチ専門相談」
- カット4（0:45-0:55）：880円の表示
- テキスト：「月880円、いつでも解約OK」

【CTA】
「保存して、次のリタッチに使ってね」
プロフィールへの誘導テキスト

【キャプション】
分け目だけ気になるのに、毎回全頭染めるのって、正直しんどい。
FOLLOWは"気になるところだけ"を、現役カラーリストがLINEで個別相談するサービス。
月880円、いつでも解約OK。

#セルフカラー #リタッチ #白髪ケア #ヘアケア #美容 #分け目 #生え際 #白髪染め #カラーリスト #LINE相談
```

#### note D1
```
タイトル：「全頭染めはもう要らない。"気になるところだけ"カラーの新習慣」

リード：
分け目の白髪、生え際のチラ見え。気になるのは"ここだけ"なのに、美容室では毎回フルカラー。
時間もお金もかかって、髪へのダメージも積み重なる。
この記事では、そんなモヤモヤを抱える方に、月880円で続けられる新しい選択肢を紹介します。

H2①：なぜ今、リタッチ専用なのか
（毎月のリタッチサイクルが3〜4週、フルカラーは3〜6ヶ月でいいケースが多いという業界知識）

H2②：FOLLOWの仕組み
（LINEで現役カラーリスト川崎さんに相談→処方→自分で塗る、というフロー）

H2③：実際の利用者の声（仮）
（既存28名の中から代表的な相談ケースを匿名で）

H2④：よくある質問
- 「自分で塗れる自信がない」→ 川崎さんが部位別の塗り方を毎回提案
- 「失敗したらどうする」→ 染めない判断もする、相談ベースだから

H2⑤：始め方
（LINE友だち追加→カウンセリング→月880円で開始）

クロージング：
「全頭染め」の常識を、ちょっと疑ってみませんか。
あなたの髪にとって本当に必要な"頻度"と"範囲"を、一緒に考えるサービスです。

▼ LINEで相談を始める
{LINE_REGISTER_URL}

タグ：#美容 #ヘアケア #白髪ケア #リタッチ #セルフカラー
```

#### Threads D1（ツリー3投稿）
```
【1投目】
分け目の白髪、3週間ごとに気になり始める。
でも美容室は3ヶ月先まで予約取れない。
セルフは怖い。
この狭間に落ちてる人、多いと思う。

【2投目】
答え：その狭間専用のサービスがある。
分け目・生え際だけリタッチする前提で、カラーリストが個別相談に乗る。
月880円、LINEだけで完結。

【3投目】
ポイントは"染めない判断もする"こと。
頭皮が荒れてる週は止める。生理前は止める。
やみくもに染めないのが、長く付き合うコツです。
（プロフィールにLINEあります）

【単発1本】
今日のセルフカラー相談で多かった質問。
「リタッチって何週間に1回がベスト？」
答え：髪質と生活で変わるけど、目安は3〜4週。
ただし白髪のスピードが速い人は2週。遅い人は5週。
"自分のサイクル"を知るのが先です。
```

## 3. note・Threads の API 連携計画

### 3-1. Threads API

- **公式API（Meta）**：2024年6月から開放、無料で利用可
- 必要なもの：Meta for Developersアプリ登録 / Threadsアカウントとの連携
- できること：投稿作成、メディア添付、レスポンス取得、ツリー投稿
- 制約：1日250投稿まで、画像5MB/動画100MB上限

実装方針：
- `apps/worker/src/services/threads-api.ts`（新規）
- 承認カードで approve → 自動投稿
- 投稿後のエンゲ取得もAPI経由でF（分析）に流す

### 3-2. note API

- **公式API**：**現時点で非公開**（2026-06時点）
- 既存の選択肢：
  - 自動ログイン+ブラウザ自動化（headless Chromium）→ TOS違反リスクあり
  - 投稿は手動、エンゲ取得のみOGP/RSSで対応
- **当面は半自動運用**：A が note記事案を生成 → ユーザー承認 → 手動投稿（コピペ）
- API開放を継続ウォッチ（Gの監視タスクに含める）

### 3-3. Instagram Reels API

- **Graph API（Meta）**：ビジネスアカウント連携で利用可
- できること：動画アップロード、キャプション投稿、ハッシュタグ
- できないこと：撮影自体は人手 → 半自動
- 実装方針：
  - 承認→動画はあらかじめR2にアップロード済み→自動投稿
  - キャプション・ハッシュタグはAが生成済み

### 3-4. 自動化ロードマップ

| Phase | 期間 | 自動化対象 |
|---|---|---|
| Phase 1 | 今〜2週間 | A生成→ユーザー承認→**手動投稿**（3プラットフォーム全て） |
| Phase 2 | 2〜4週間 | Threads自動投稿開始（Meta API連携） |
| Phase 3 | 1〜2ヶ月 | Reels自動投稿（事前撮影分のキャプション差し込み） |
| Phase 4 | 継続観測 | note API開放を待つ、または別の長文プラットフォーム評価 |
