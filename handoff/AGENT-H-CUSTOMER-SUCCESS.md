# エージェントH：カスタマーサクセス（解約防止・継続率向上）

作成日: 2026-06-10
位置づけ: 8番目のエージェント
役割: 既存サブスク顧客の継続率最大化。1年5,000名ゴールに必須。

---

## 1. なぜ必要か

サブスク事業の最大の敵は**解約**。  
新規獲得（A/C/Gが担当）と同じくらい、**既存顧客の維持**が重要。  
月解約率を1%下げるだけで、12ヶ月後のMRRが大きく変わる。

---

## 2. 役割

- 顧客ごとの**継続リスクスコア**を算出
- リスク高の顧客に**先回り**でケア提案
- 解約申し出を受けた時の**引き留めフロー**を運用
- 解約済み顧客の**復帰オファー**設計

---

## 3. 起動条件

| トリガー | 内容 |
|---|---|
| 毎朝の「おはよう」 | 全顧客のリスクスコア更新、TOP10をユーザーへ提示 |
| LINE 14日無返信 | 自動で「お元気ですか」カードをユーザー承認待ちに |
| カウンセリング未実施 30日 | フォローカード提案 |
| 解約申し出検知（キーワード） | 即時、引き留めスクリプト案を起票 |
| 解約後7日 | 復帰オファーの提案 |

---

## 4. 継続リスクスコアの算出

各顧客に対し以下を加点：

| 要素 | 加点 |
|---|---|
| LINE 14日無返信 | +20 |
| LINE 30日無返信 | +40 |
| カウンセリング未実施 | +15 |
| 直近の相談で「美容室予約取れた」発言 | +10 |
| 直近の相談で「忙しい」「合わない」発言 | +25 |
| 課金日が翌週以内 | +5 |
| 連続課金3ヶ月未満 | +10（初期離脱リスク） |
| 既読スルー連発 | +15 |
| ネガティブな絵文字（泣・困）多用 | +10 |

スコア閾値：
- 0〜29：低リスク
- 30〜59：中リスク（観察）
- 60以上：高リスク（先回り介入）

---

## 5. 介入パターン

### 5-1. 「お元気ですか」カード（低〜中リスク）
- 軽い問いかけ「最近のリタッチ、どうでしたか？」
- 季節ネタ絡め（梅雨→広がり、夏→紫外線）

### 5-2. 個別オファーカード（中〜高リスク）
- 川崎さんからの個別メッセージ案
- 「1回無料で塗布動画送ります」など追加価値

### 5-3. 解約引き留めフロー（解約申し出時）
1. 理由を聞く（責めない）
2. 該当する不満に**具体的な解決案**を提示
3. 「お休み」プラン（30日凍結、880円停止）の提案
4. それでも解約なら、感謝＋将来の復帰歓迎メッセージ

### 5-4. 復帰オファー（解約後7日以降）
- 解約理由に応じた内容で再アプローチ
- 「初月割引（550円）で再開可能」
- 押し付けは厳禁。3回までで停止。

---

## 6. 顧客カテゴリ別の運用

| カテゴリ | 接触頻度 | トーン |
|---|---|---|
| 新規（1ヶ月以内） | 週2回 | 立ち上がり支援、安心感重視 |
| 安定（3ヶ月以上） | 月2回 | 季節ネタ、新情報の共有 |
| 高エンゲ（毎月相談） | 月3回 | 関係深化、紹介依頼候補 |
| サイレント（無返信中） | 月1回 | 重くならない問いかけ |
| 解約候補（高リスク） | 即時 | 個別対応 |
| 解約済み | 7日・30日・90日の3回 | 押し付けない |


## 8. 紹介依頼への展開

H が**継続が長く満足度が高い顧客**を識別 → 紹介依頼カードを提案：

```
「◯◯さん、いつも続けてくださってありがとうございます。
 もしよかったら、お知り合いに紹介していただけませんか？
 ご紹介で1ヶ月無料になります（おふたりとも）」
```

紹介リンク（unique UTM）を発行し、CV元を追跡。

---

## 9. 法務・倫理ガード

- 解約引き留めは「1回まで」。しつこい引き留めは違法スレスレ。
- 解約理由をハラスメント的に問いただすのはNG。
- 復帰オファーは3回まで、それ以降は完全停止。
- メンタル系のキーワードを検知したら**即時介入停止**してユーザーに上げる。

---

## 10. KPI

- 月解約率（目標：5%以下、最終的に3%）
- 平均継続月数（目標：6ヶ月以上）
- 復帰率（解約済みの再契約率、目標：5%）
- 紹介経由の新規CV数（目標：月3名）
