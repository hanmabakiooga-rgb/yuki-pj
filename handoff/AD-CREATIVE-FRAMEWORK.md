作成日: 2026-06-10
役割: エージェントC が広告台本を量産するための設計図

---

## 1. 月3万円の使い方

| 区分 | 配分 |
|---|---|
| Instagram フィード広告 | 40%（¥12,000） |
| Instagram Reels 広告 | 30%（¥9,000） |
| Threads 広告（解禁後） | 15%（¥4,500） |

広告セット：3〜5本を常時走らせ、CPAで間引く

## 2. 広告フォーマット別の構造

### 2-1. Instagram Reels 広告（縦動画）

```
[0-3秒] 共感フック
  → 視聴者の悩みを言語化
  → 大きな白テキスト＋強い表情

[3-10秒] 問題提起
  → 「美容室は予約取れない、セルフは怖い」
  → カット切替で離脱防止

[10-20秒] 解決提示
  → FOLLOWの仕組みを15秒で
  → LINE画面・川崎さん登場

[20-25秒] CTA
  → 「プロフから3秒で始められます」
  → 880円・解約自由をテキストで
```

### 2-2. Instagram フィード広告（静止画）

```
[1枚目] フック画像
  → 大きなコピー、視覚的に強い

[2-4枚目] 比較・説明
  → ビフォー/アフター（同意・改変なし）
  → 仕組みのイラスト

[5枚目] CTA
  → LINE登録ボタン強調
```

### 2-3. Threads 広告（解禁後）

```
[1投目] 問題提起 1文
[2投目] FOLLOWの解決 1文
[3投目] CTA（リンク）
```

## 3. クリエイティブのバリエーション設計

毎月3パターンを並走テスト。1ヶ月で1勝者を選定 → 翌月の主軸に。

### パターンA：悩み代弁型
- 「分け目の白髪、毎月気になる人へ」
- 共感に振り切る

### パターンB：意外性型
- 「美容室は3ヶ月先まで予約取れません。だから自宅で。」
- 「染めない判断、もアリ」
- ハッとさせる

### パターンC：実例型
- 「6ヶ月続けた40代の声」
- 信頼・社会的証明に振る

## 4. ターゲティング設定

### ペルソナ1：30〜40代女性、関東都市部
- 興味：美容、ヘアケア、子育て、忙しい働く女性
- ベース：30〜45歳、女性、都内+横浜+川崎+さいたま

### ペルソナ2：40〜50代女性、地方都市
- 興味：白髪ケア、頭皮悩み、節約
- ベース：40〜55歳、女性、政令指定都市

### ペルソナ3：35〜50代男性（小規模テスト）
- 興味：分け目の白髪、見た目印象、出張多い
- ベース：35〜50歳、男性、都内

ターゲット切替テストは月1回まで。

## 6. 入稿フロー

1. C が台本生成 → E 法務チェック → ユーザー承認
2. 川崎さんと撮影日調整（月1回、半日）
3. 編集はユーザー or 外注（予算内）
4. R2 に動画アップロード
5. Meta広告マネージャ手動入稿（初期）
6. KPI監視（CPA, CTR, CVR）

将来は5〜6を自動化。

---

## 7. 停止判定

C が毎日チェック：

```
3日連続でCPAが¥3,000超 → 即停止 + 改善提案
CTR が 0.5% 下回り続ける → 1週間で停止
リーチが目標の30%以下 → ターゲット見直し
```

停止後は別案を投入、もしくは予算を生き残った案に集中。

---

## 8. 法務チェックリスト（E）

広告は必ず E を通す：

- [ ] 効能効果の断定なし
- [ ] 「絶対」「100%」「保証」なし
- [ ] 競合への直接的な誹謗なし
- [ ] ビフォーアフター画像の同意・改変なし
- [ ] 「医療」「治る」表現なし
- [ ] 特商法表記へのリンク明示
- [ ] 月額・解約条件が明示
- [ ] 個人情報の取扱いリンク
