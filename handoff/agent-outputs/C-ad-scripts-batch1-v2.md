## 共通設定

- **媒体**：Instagram Reels（縦動画 60-90秒）
- **予算**：¥1,000/日 × 7日 = ¥7,000/本
- **ターゲット**：35-50代女性、関東＋政令指定都市＋大阪
- **目標CPA**：¥1,500以下

### 全台本に必須で含める要素
1. 川崎さんの権威性（「20年・何万人・大阪専門店」のうち最低1つ）
2. 「気になるところだけ」を明示（全頭ではない）
3. 「プロ用商材」（市販品ではない）
4. 月880円・いつでも解約OK
5. 商材購入は任意（押し付けない）

## 台本①「全頭染め、もう要らない」（最重要メッセージ）

### 狙い
- FOLLOWの**最大の独自性「気になるところだけ」**を直撃
- 顧客の「下がる4つ」（頭皮負担・時間・コスト・失敗リスク）を訴求

### 台本（75秒）

```
[0-2秒] 大テキスト：
「40代の白髪、毎月"全頭"染めてませんか？」
→ 全頭にカラー剤を塗っている映像

[2-8秒] 共感パンチ
- ナレ：「気になるのは"分け目だけ"なのに」
- カット：分け目のアップ、ピンポイントの白髪
- テキスト：「染めてるのは"頭全体"」

[8-25秒] 問題提起
- ナレ：「毎月全頭染めると、頭皮が薬剤を浴び続ける」
- カット：薬剤を浴びた頭皮のイメージ
- テキスト：「将来の頭皮への蓄積、時間、コスト、全部が積み上がる」

[25-50秒] FOLLOWの提案（独自軸）
- 川崎さん登場（白衣 or サロン背景）
- テロップ：「川崎｜現役カラーリスト20年 / 大阪カラー専門店経営」
- ナレ：「気になるところだけ、染める」
- カット：分け目のみ塗布、5分で終わる映像
- テキスト：「将来の頭皮負担も、時間も、コストも、全部下がります」

[50-65秒] プロ用商材の安心
- ナレ：「使うのは、私が現場で扱っているプロ用の薬剤」
- カット：商材パッケージ、肌に優しい印象のイメージ
- ナレ：「市販品より低刺激、染めた後の頭皮ケアまで一緒に組みます」
- テキスト：「商材の購入は任意です。他で買ってもOK」

[65-75秒] CTA
- 大テキスト：「月880円、いつでも解約OK」
- 川崎さん「LINEで分け目の写真送ってください、塗る場所だけ毎回お伝えします」
- LINEアイコン
```

### キャプション
```
40代の白髪、毎月"全頭"染めてませんか？
気になるのは分け目だけなのに、頭全体を染め続けると
頭皮への負担も、時間も、コストも、ぜんぶ積み上がる。

現役カラーリスト20年、大阪のカラー専門店経営の私が
「気になるところだけ」をプロ用商材で染める方法を
LINEで個別に提案します。

商材購入は任意、他で買ってもOK。
月880円、いつでも解約。

▶ プロフから写真送って相談スタート

#セルフカラー #白髪染め #リタッチ #分け目 #大阪カラーリスト
```

### KPI想定
- CTR：2.3%（独自軸+権威性で高め想定）
- CV率：5%
- CPA：¥1,200


## 台本③「染める・染めないを毎月一緒に決める」（差別化の核）

### 狙い
- 「染めない美容師」との明確な差別化を訴求
- グレイヘア移行を迷う層も、現役染め層も、両方拾う

### 台本（68秒）

```
[0-2秒] 大テキスト：
「染めるか、やめるか、毎月迷ってる人へ」
→ 鏡を見る女性の後ろ姿

[2-12秒] 共感
- ナレ：「美容師は染めることを前提に話す」
- カット：美容室の様子
- ナレ：「グレイヘア派は、移行成功者しか語らない」
- カット：SNSのスクロール

[12-25秒] FOLLOWのスタンス
- 川崎さん登場
- テロップ：「川崎｜現役カラーリスト20年 / 大阪カラー専門店経営」
- ナレ：「染める・染めない、両方ありです」
- テキスト：「無理に続けさせない。やめさせもしない」

[25-50秒] 提案の中身
- ナレ：「あなたの髪と頭皮を毎月見て、"今月どうする"を一緒に決めます」
- カット：LINE画面「今月は染めずに様子見ましょう」のメッセージ
- ナレ：「染める時は気になるところだけ、プロ用商材で安全に」
- テキスト：「頭皮ケアの提案も、毎月セットで」

[50-65秒] 信頼
- ナレ：「20年の現場経験、何万人のカラーをやってきた目で」
- テキスト：「月880円、いつでも解約OK、商材購入は任意」

[65-68秒] CTA
- 大テキスト：「LINEで今の髪の写真を送ってください」
```

### キャプション
```
染めるか、やめるか、毎月迷う。
そんな人に「両方アリ」と言える美容師がいてもいい。

現役カラーリスト20年、大阪のカラー専門店経営の私が
あなたの髪と頭皮を毎月見て"今月どうする"を一緒に決めます。

染める時は気になるところだけ、プロ用商材で。
染めない月は頭皮ケアを。
月880円、商材購入は任意。

▶ プロフから髪の写真送って相談スタート

#グレイヘア #白髪 #50代 #大阪カラーリスト
```

- CTR：1.8%

## E（法務）チェック

| 項目 | 結果 |
|---|---|
| 効能効果の断定 | ✅ なし |
| 「絶対」「100%」「保証」 | ✅ なし |
| 「美容室不要」 | ✅ なし（サロンと"あいだ"の表現に統一） |
| 競合誹謗 | ✅ なし |
| 月額・解約条件の明示 | ✅ あり |
| 商材購入の任意性 | ✅ 明示（押し付けNG表現なし） |
| 川崎さんの権威性表記 | ⚠ 「20年」「何万人」は事実確認後に確定 |
| ビフォーアフター画像 | ⚠ 撮影時に同意必須 |
