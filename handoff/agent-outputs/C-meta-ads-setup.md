## 5. 運用ルール（C が毎日チェック）

| 条件 | アクション |
|---|---|
| CPA ¥3,000 超え 3日連続 | その広告を停止、ユーザーへ報告 |
| CTR 0.5% 未満 7日 | クリエイティブ差し替え |
| 1広告に予算の70%以上集中 | そのまま（Metaの最適化を尊重） |
| 週次で全広告 CPA ¥2,000 超 | 訴求軸の再検討（G と協議） |

## 6. 入稿手順（ユーザー作業、初回のみ30分）

1. Meta広告マネージャ → キャンペーン作成 → 目的「リード」または「トラフィック」
2. 上記§1の構造どおりにキャンペーン/広告セット/広告を作成
3. §2のターゲティングを設定
4. 動画素材（Vrew/CapCutで制作したもの）をアップロード
5. §3のテキストをコピペ
6. §4のUTM付きリンクを設定
7. 公開前に「プレビュー」で見え方確認 → 公開

※2回目以降は広告の差し替えのみ（5分）
