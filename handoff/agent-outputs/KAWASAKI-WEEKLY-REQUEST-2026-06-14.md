## メッセージ本体（このまま貼り付け）

```

今週、お願いしたいことを3つだけ、まとめて送ります。

──────────
① 自撮り収録の状況確認（10分）

撮影できましたか？

・撮影済み → 動画ファイルを送ってください
・まだ → いつ撮れそうか教えてください
・難しい → 内容調整します、率直に教えてください

──────────
② 既存28名の分類（15分）
──────────

解約防止キャンペーンの文面が完成しました。
グループA/B/Cに分けるだけお願いします。

【A：高エンゲ・長期】継続3ヶ月以上 + 月1回以上相談 + 反応良好
【B：標準・観察】継続1〜3ヶ月 or 相談頻度が月1未満
【C：高リスク】14日以上未返信 or カウンセリング未完了

例：
A：田中さん、鈴木さん、…
B：佐藤さん、…
C：山田さん、…

──────────
③ LP掲載の許諾確認（5分）
──────────

ホームページに以下を載せて大丈夫ですか？

・現役カラーリスト20年

→ OK / 修正したい部分あり、で返してください。

写真は別途送ってもらえれば差し替えます。
（届くまでは仮の画像で公開します）

──────────

3つすべて、自分のペースで大丈夫です。
気になることあれば質問ください。
お願いします。
```

## 補足：川崎さんから返ってきたときの対応

| 返信内容 | こちらの動き |
|---|---|
| ①動画が届いた | C エージェントが Vrew/CapCut で編集 → Meta広告入稿 |
| ①まだ | 撮影日を再設定、リマインド |
| ②A/B/C分類が来た | H エージェントがD2から送信開始（3日間で全28名） |
| ③LP掲載OK | D Issue #1（LPリライト）の写真placeholderが本物に置換可能 |
| ③修正したい | 表現を調整して E法務再チェック |
