# B実働：LINE返信テンプレ集（川崎さん用ドラフト）

実行: エージェントB（LINE返信ドラフト）
作成日: 2026-06-10
位置づけ: 川崎さんが**そのままor微調整して使える**返信テンプレ
状態: ドラフト、E法務OK、川崎さんレビュー待ち

---

## 1. テンプレ集の使い方

- B が顧客からのLINE着信に対し、**まず該当テンプレを選択**
- 顧客固有の情報（名前・髪質・直近の相談）を埋め込む
- E法務チェック → 承認カード生成 → 川崎さん or ユーザー承認 → 送信

テンプレに無いパターンは B が新規生成 → ナレッジに追加。

## 4. 言い回し・トーンの統一ルール

### 必ず守る
- 一人称「川崎」（私 / 我々 ではなく）
- 「〜です／〜ます」調を基本
- 文末に「― 川崎」のサイン
- 顧客名を冒頭に呼びかけ

### 避ける
- 「やってあげる」「教えてあげる」（上から目線）
- 「すぐに」「今すぐ」（煽り）
- 「絶対」「100%」（断定）
- 専門用語の連発（噛み砕いて）

### 文字数
- 通常返信：100〜300字
- 詳細解説：300〜600字
- 雑談：50〜150字
