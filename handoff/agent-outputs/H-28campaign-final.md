## 返信パターン別の対応フロー

### グループA で「紹介したい」と返ってきた
→ 紹介リンクを発行して送付（H-referral-program-v2.md の仕様）
→ リンク未実装の間は「お知り合いに私のLINEを教えてください、『◯◯さんの紹介』と一言添えてもらえれば対応します」で代替

### グループB で写真が送られてきた
→ 川崎さんが通常の相談フローで対応（48時間以内）
→ 対応後、Hがその顧客のリスクスコアを下げる

### グループC で「お休みしたい」
→ 「承知しました」+ 課金停止の手続き
→ Stripe の pause 機能 or 手動キャンセル+メモ
→ 30日後に「そろそろ調子はどうですか」を1回だけ

### グループC で「解約したい」
→ 引き留めは**1回だけ**：「理由をお聞きしてもいいですか」
→ 解約処理 + 感謝メッセージ
→ 「いつでも戻ってきてください、データは残しておきます」

### 返信なし（全グループ）
→ 追撃しない。次の接触は1ヶ月後の季節ネタまで空ける
