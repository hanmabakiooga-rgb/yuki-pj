## 素材チェック（Vrew/CapCut編集後）

### 動画スペック確認

- [ ] アスペクト比：**9:16**（縦型、Reels専用）
- [ ] 解像度：1080 × 1920px 以上
- [ ] 長さ：**15〜30秒**（30秒超はリーチが下がる）
- [ ] ファイル形式：MP4
- [ ] ファイルサイズ：4GB 以下（通常100MB以下になるはず）
- [ ] 音声：あり（テロップも入れると無音環境でも伝わる）
- [ ] 冒頭2秒：主訴求・川崎さんの顔または印象的な画が入っている
- [ ] テロップ：文字が小さすぎない（スマホ画面で読める）
- [ ] テロップ：法務NGワード（「絶対」「100%」「治る」）が入っていない

### 台本ごとの必須要素チェック

#### 台本①「全頭染め、もう要らない」
- [ ] 冒頭：「全頭染め」「分け目だけ」のどちらかのワードが0〜2秒で出る

- [ ] 月額・解約：「月880円」「解約自由」が画面テキストで入っている
- [ ] CTA：「LINEで相談」「プロフのリンク」等の誘導がある

#### 台本②「ハイライト救済」
- [ ] 冒頭：「ハイライト」「根元」の悩みが0〜2秒で出る
- [ ] ビフォーアフター的な視覚変化がある（ない場合は川崎さん解説のみでも可）
- [ ] 「染まるハイライト部分を残す」概念が伝わっている
- [ ] CTA：LINE誘導

#### 台本③「染める・染めない両方アリ」
- [ ] 冒頭：「迷っている」共感フックが0〜2秒で出る
- [ ] 「両方アリ」の言葉またはニュアンスが入っている
- [ ] 頭皮ケア言及：あると理想（なくてもOK）
- [ ] CTA：LINE誘導

## Meta広告マネージャ 入稿手順（初回30分）

### キャンペーン作成

1. **広告マネージャ** を開く（business.facebook.com）
2. **「+作成」** をクリック
3. 目的：**「トラフィック」**（または「見込み客」）を選択
   - ※「リード」はLPのLINEボタンのコンバージョン計測が必要→ピクセル未設置なら「トラフィック」先行
4. キャンペーン名：`FOLLOW_獲得_2026-06`
5. 予算：**¥1,000/日**（キャンペーン予算最適化 CBO ON）

### 広告セット1（関東先行）設定

6. 広告セット名：`35-50女性_関東`
7. コンバージョン：「ウェブサイト」→ LP URL
8. **オーディエンス設定：**
   - 年齢：35〜50
   - 性別：女性
   - 地域：東京 / 神奈川 / 埼玉 / 千葉
   - 詳細ターゲティング → 「追加」→ 検索欄に：
     - `ヘアケア`（興味・関心）
     - `セルフケア`（興味・関心）
     - `ヘアカラーリング`（興味・関心）
   - 除外：「美容師」（職業）を除外に追加
9. **配置：**「手動配置」を選択 →
   - **Instagram：リール、ストーリーズ、発見タブ** のみチェック
   - Facebook は外す（ターゲット層のメイン利用がInstagram）

### 広告作成（3本分）

10. 広告名：`広告1-1_全頭染め不要`
11. クリエイティブ：動画アップロード
12. 本文テキスト：C-meta-ads-setup.md §3 の「広告①メインテキスト」をコピペ
13. 見出し：`分け目だけ、染めればいい。`
14. 説明文：`月880円・写真を送るだけ`
15. リンク先：`https://follow-lp.pages.dev?utm_source=meta&utm_medium=paid&utm_campaign=acq202606&utm_content=ad1`
16. CTA ボタン：「詳しくはこちら」
17. 「広告1-2_ハイライト救済」「広告1-3_染める染めない」も同様に追加（UTM末尾だけad2/ad3に変える）

### 公開前の最終確認

- [ ] プレビューボタン → スマホ表示で文字が読める
- [ ] リンクをタップ → LPが正しく開く
- [ ] 月額880円がLPのファーストビューまたはCTA周辺に表示されている

## 補足：Metaピクセル（計測精度向上）

現在LPにピクセル未設置のため、コンバージョン計測は「LPへのクリック数」で代替。  
D Issue #1（LP改修）と合わせて、以下をLPの`<head>`に1行追加するだけ：

```html
<!-- Meta Pixel Code -->
<script>!function(f,b,e,v,n,t,s)...fbq('init', 'YOUR_PIXEL_ID');</script>
```

CODEX投入時のメモ：
```
LP の <head> に Meta Pixel コードを追加。
pixel_id は wrangler secret NEXT_PUBLIC_META_PIXEL_ID で管理。
LINEボタンクリックイベント fbq('track', 'Lead') を発火。
```
