## 1. 設計の前提

- 既存サブスク 28名
- 1年 5,000名 ゴールに紹介経由は**必須の獲得チャネル**
- 既に管理画面にアフィリエイト機能あり → 紹介リンクの仕組みは流用可能
- 「押し付けない」「商材任意」のスタンスと同じ精神で**紹介も押し付けない**

---

## 2. プログラム仕様

### 2-1. 報酬構造

| 紹介者 | 被紹介者 |
|---|---|
| **1ヶ月無料**（次回課金スキップ） | **初月無料** |

両者にメリット、シンプル、計算しやすい。

### 2-2. 最大紹介数の上限

- 紹介者1人あたり：年間6回まで（半月に1回ペース上限）
- ノルマ・営業色を消すため、ゲーミフィケーションは入れない

### 2-3. 招待リンクの形式

```
https://follow.app/r/{8桁の招待コード}
```

- 8桁英数字、覚えやすい
- LINE / メール / X / Threads 共有用シェアテンプレ自動生成
- UTM パラメータ付き（utm_source=referral）

### 2-4. 紹介の有効化条件

- 被紹介者が**初月課金を完了**した時点で紹介者にも報酬付与
- カウンセリングだけで止まった場合は無効（不正防止）
- 紹介された人がすぐ解約した場合は紹介者の報酬も取り消し

---

## 3. 紹介依頼の出し方（押し付けない）

### 3-1. 「いつ・誰に」声をかけるか（H判定ロジック）

候補：
- 継続3ヶ月以上
- 月1回以上の相談あり（エンゲ高）
- 過去のメッセージで**ネガティブ表現なし**
- 自分から「良かった」「助かった」と言ってくれた

### 3-2. 依頼メッセージ案

```
◯◯さん、いつも続けてくださってありがとうございます。

実は、◯◯さんに「ぜひ続けてほしい」と
私(川崎)が感じる方々に、お声がけしています。

もしよかったら、お知り合いに紹介していただけませんか？
紹介で、おふたりとも1ヶ月無料になります。

▶ 紹介リンク：{REFERRAL_URL}

押し付けるつもりはまったくないので、
気が向いたときだけで大丈夫です。
紹介しなくても、私のサービスへの気持ちは変わりません。

― 川崎
```

### 3-3. 送信ルール

- 1人につき**生涯3回まで**（半年に1回ペース）
- 返事がなくてもしつこく送らない
- 「紹介しない」と返ってきたら即座にリスト除外

---

## 4. 被紹介者の入口体験

### 4-1. 招待リンクをタップした時の挙動

1. LP に着地、「◯◯さんから紹介を受けました」と冒頭表示
2. 「初月無料、いつでも解約OK」を強調
3. LINE登録 → カウンセリング → 課金フローへ
4. 課金完了 → 紹介者にも自動で1ヶ月無料が反映

### 4-2. 被紹介者専用のメッセージ

```
{紹介者の名前}さんからの紹介、ありがとうございます。

FOLLOWは、現役カラーリスト川崎が
"気になるところだけ"のカラーをLINEで個別相談するサービスです。

▶ 初月無料、いつでも解約OK
▶ カウンセリング3分で始められます

何か質問あれば、いつでも遠慮なくどうぞ。
```

## 5. 法務（E）チェック

- ✅ 景表法：「両者1ヶ月無料」は不当な利益供与に該当しない
- ✅ 特商法：報酬条件を LP / 利用規約に明記する必要あり
- ✅ 個人情報保護：紹介者と被紹介者の紐付けは内部処理のみ、第三者開示しない
- ⚠ 「紹介すれば◯◯円もらえる」の金銭表示は MLM 誤認の恐れ → 「無料」「割引」の表現に統一
- ⚠ 過度な煽り表現（「今だけ」「限定」）は使わない

---

## 7. 失敗時のシナリオ

| 状況 | 対応 |
|---|---|
| 紹介数が伸びない | 報酬を「2ヶ月無料」に増額 or 紹介依頼の頻度見直し |
| 紹介者がすぐ解約 | 報酬取り消し、Hが理由ヒアリング |
| スパム紹介（無関係者の登録） | 招待コードを使い切り型（1コード1回）に変更 |
| クレーム発生 | 即時謝罪 + プログラム見直し |
