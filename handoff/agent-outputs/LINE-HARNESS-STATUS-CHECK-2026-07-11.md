## §1 スマホでできる確認（5分・LINEアプリ）

> **テストの安全ルール**：本番のお客様には一切テスト送信しません。以下はすべて「テスト用のLINEアカウント」（家族の端末、またはご自身のサブアカウント）から、FOLLOWの公式アカウントに対して行います。テスト前に川崎さんへ「今からテストメッセージを送ります」と一言伝えておくと、通知が来ても慌てずに済みます。テスト後、そのアカウントはブロック解除せずそのまま放置でOKです。

- **見るべき結果**：追加した直後（数秒以内）に、挨拶メッセージが自動で1通届く

### Q3. 営業時間外の自動応答が返るか

### Q4. 緊急ワードの検知が動くか

## §2 PCでできる確認（5分・ブラウザ）

### Q6. Cloudflare WorkersのBotプログラムがデプロイ済みか

> **Cloudflare Workers**とは：LINE Botのプログラムを24時間動かしてくれるクラウドサービスです。「デプロイ済み」＝プログラムが本番で動いている状態、という意味です。

- **やること**：
  1. https://dash.cloudflare.com にログイン
  2. 左メニューの「**Workers & Pages**」（または「コンピューティング」）をクリック
  3. 一覧に line-harness / follow-worker のような名前のプロジェクトがあるかを見る
  4. あればクリックして「最終デプロイ」「Last deployed」の日付を確認
- **見るべき結果**：Workerが1つ以上存在し、デプロイ日が表示されている
- **Yes / No ＋ 最終デプロイ日**（例：Y、2026-06-20）

### Q7. D1データベースにcustomersテーブルとデータがあるか

> **D1**とは：Cloudflareが提供するデータベース（顧客名簿の保管庫）です。LINE登録したお客様の情報がここに記録される設計になっています。

- **やること**：
  1. 同じCloudflareダッシュボードの左メニューで「**ストレージとデータベース**」→「**D1 SQL データベース**」（英語表示なら Storage & Databases → D1）をクリック
  2. `line-harness` のような名前のデータベースをクリック
  3. 「**テーブル**（Tables）」タブをクリック
  4. `customers` という名前のテーブルがあるか、あればクリックして中身の行数を見る
- **見るべき結果**：customersテーブルが存在し、28行前後（既存のお客様分）のデータが入っている。さらにQ1のテスト友だち追加をした後なら、1行増えているはず
- **Yes / No ＋ おおよその行数**（例：Y、29行。テーブル自体がない場合は「テーブルなし」、D1データベース自体がない場合は「D1なし」と書いてください）

### Q8. KPI用Google Sheetsに6タブがあるか

> **FOLLOW-KPI Sheets**とは：日々の数字（登録数・解約数など）を記録するGoogleスプレッドシートです。

- **やること**：https://docs.google.com/spreadsheets/d/1Xshvq2dIJKoTLwU8E4VBR-alySOW42h96Uh7NQji4B0/edit を開き、画面下部のタブを見る
- **見るべき結果**：`daily` / `weekly` / `monthly` / `experiments` / `monitoring` / `dashboard` の6タブがある
- **Yes / No**（一部だけある場合は、あるタブ名を列挙）

### Q9. dailyタブに数値が入っているか
- **やること**：同じシートの `daily` タブを開く
- **見るべき結果**：1行目にヘッダー（date, lp_visits, ...）があり、2行目以降に日付＋数値が1行でも入っている
- **Yes / No ＋ 最後に入力された日付**（例：Y、最終行は2026-06-12）
