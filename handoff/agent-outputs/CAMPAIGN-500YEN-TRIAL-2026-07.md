# 初月500円お試しキャンペーン 実行指示書（2026-07）

作成日: 2026-07-11
対象: 既存LINE友だち（サブスク未登録者）＋ Threads公式アカウント（新規獲得訴求）
価格設計: **初月500円 → 2ヶ月目以降 通常880円**（自動）
配信方法: 手動一括配信（H-28campaignと同形式）＋ Threads自動投稿テンプレへの組み込み
法務: 本書§4のE法務チェック通過が配信・投稿の前提条件

---

## 0. キャンペーン概要

| 項目 | 内容 |
|---|---|
| 対象①（LINEキャンペーン） | 既にLINE友だち登録済みだが、サブスク未登録の方 |
| 対象②（Threads公式） | 未フォロー・未登録の新規層（獲得フック） |
| オファー | 初月500円、2ヶ月目から通常の880円に自動移行 |
| 目的 | 「登録したが決済に進んでいない」層の後押し＋新規層の心理的ハードル低下 |
| 期間 | ユーザー判断で開始・終了日を決定（開始したら本書§6のトグルOFF手順で終了） |

## 1. 対象者の特定方法（LINEキャンペーン）

人数規模的に、D1データベースのクエリ調査は不要と判断。以下の手動照合で進める：

1. LINE公式アカウント管理画面（https://manager.line.biz/）→「友だちリスト」を開く
2. 現在契約中（サブスク決済済み）の顧客リストと突き合わせ、**友だちだが契約リストに無い人**を抽出
3. 抽出したリストに対して、本書§3のメッセージテンプレを手動で個別送信（H-28campaignと同じ運用）

※ 契約中リストの管理方法（Square側の契約者一覧、または別途Sheets管理）が明確であれば、そちらを正とする。

---

## 2. 決済導線（要ローカル側での確認・設定）⚠️

**このセッションからはSquare決済の実際の設定を確認できません。以下はローカル（Claude Desktop、Square管理画面にアクセスできるセッション）で確認・設定してください。**

### 確認・設定タスク

1. 現行の880円決済リンクがSquareの**サブスクリプション商品**として設定されているか確認
2. サブスクリプション商品に「**初回請求額を500円にする**」設定（Square の「Trial period」または「Introductory price」機能）が存在するか確認
   - Squareのサブスクリプションプランには「試用期間（Trial Period）」機能があり、無料または割引価格での初期期間を設定可能な場合がある。管理画面で確認すること
3. 上記機能がない場合の代替案：
   - **案A**: 500円用の別決済リンクを新規作成し、初月分だけ手動で処理→2ヶ月目からは通常880円リンクへの切り替えを手動管理（運用負荷は増えるが確実）
   - **案B**: クーポンコード／ディスカウントコード機能があれば、初回のみ適用されるコードを発行
4. どの方式を採るか決定したら、本書§3のメッセージテンプレ内の決済リンク部分を確定する

**重要**: 決済まわりの設定変更は取り消しづらい／既存契約者に影響する可能性があるため、実際の変更前に必ずテスト（自分のアカウントで少額決済テスト等）を行うこと。

## 3. メッセージテンプレ（LINEキャンペーン・対象①向け）

送信時間帯: 平日10:00–14:00（H-28campaignの運用時間帯に準拠）

```
{name}さん、こんにちは。川崎です。

FOLLOWにご登録いただいてから少し経ちましたが、
いかがお過ごしですか？

「気になるけど、まだ始めていない」という方向けに、
初月だけ500円でお試しいただけるようにしました。
（2ヶ月目からは通常の月880円になります）

気になる分け目・生え際だけでも、
まずは写真を1枚送っていただければ、
今の状態に合わせたご相談ができます。

合わなければ、いつでも解約いただいて大丈夫です。

決済はこちらから：
{決済リンク}

― 川崎
```

### 返信対応（H-28campaign §6チートシートを流用）

- 「申し込みます」→ 決済確認後、通常のオンボーディングフローへ
- 「今回は見送ります」→ 「承知しました、また気が向いたらいつでもご連絡ください」で終了、追撃しない
- 質問が来た場合 → 通常の相談フロー（48時間以内対応）

## 4. E法務チェック（配信前に必須）

以下を満たしていることを確認（`E-legal-checklist-prompt.md`基準）：

- [x] 月額料金が明示されている（初月500円、2ヶ月目以降880円と両方明記）
- [x] 「今だけ」「限定」「先着」等の不当な有利誤認表現を使用していない（本テンプレでは未使用）
- [x] 解約の自由を明記（「いつでも解約いただいて大丈夫です」）
- [x] 断定的効果表現なし（「染まる」「治る」等の使用なし）
- [x] 川崎さんの権威性は本メッセージでは必須要件外（既存友だち向けのため省略可、ただしTemplateには含めても良い）
- [x] 自動更新（2ヶ月目から880円に自動移行）の説明あり

**判定: OK**（既存の28campaignテンプレと同水準の法務基準をクリア）

## 5. Threads公式アカウント（@kokodake2026）への組み込み

「現在のThreads自動投稿もキャンペーン打ち出しで同じ設定にしていく」の対応。既存の `sns_templates` シート（GAS自動投稿システム）に、以下のキャンペーンテンプレを**直接行として追加**する（Main.gsの再デプロイ不要）。

2. 以下の行を追加（既存のヘッダー列順: `id, slot, theme, coreMessageId, text, active, (空欄), uses_count, notes`）

| id | slot | theme | coreMessageId | text | active | (空欄) | uses_count | notes |
|---|---|---|---|---|---|---|---|---|
| `camp500_morn_001` | morning | campaign | 6 | 下記本文A | TRUE | | 0 | 500円キャンペーン・朝 |
| `camp500_noon_001` | noon | campaign | 6 | 下記本文B | TRUE | | 0 | 500円キャンペーン・昼 |
| `camp500_night_001` | night | campaign | 6 | 下記本文C | TRUE | | 0 | 500円キャンペーン・夜 |

### 5-5. E法務チェック（Threads用・上記3本文共通）

- [x] 「今だけ」の使用なし（時間的切迫を煽らず、単に「今なら」の案内表現に留める）
- [x] 月額料金（880円）と初月価格（500円）を両方明記
- [x] 解約自由の明記（本文B）

**判定: OK**

## 6. キャンペーン終了時の手順

1. `sns_templates` シートで上記3行の `active` 列を `TRUE` → `FALSE` に変更（GASの `generateTomorrowPosts()` は active=TRUE のみ抽選対象にする設計のため、これだけで自動投稿からキャンペーン文言が外れる）
2. LINEキャンペーンは既に個別送信済みのため、追加対応不要（追撃しない）
3. 決済リンクを§2で新規作成していた場合、Square側で無効化 or 通常880円リンクへ差し戻し
