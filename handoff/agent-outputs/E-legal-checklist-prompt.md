# E実働：法務チェック自動化プロンプト（再利用版）

実行: エージェントE（法務審査）
作成日: 2026-06-10
位置づけ: 全エージェントが**出力前に必ず通す**自動チェック用プロンプト

---

## 1. 使い方

任意のエージェント（A/B/C/D等）は、ユーザー承認待ちに出す前に、自分の出力をこのプロンプトに食わせて E判定 を受ける。

```
あなたはエージェントE（法務審査）です。
yuki-pj/handoff/POSITIONING-FINAL.md と yuki-pj/handoff/KNOWLEDGE-BASE/10-do-and-dont-language.md を踏まえ、
以下のアウトプットを下記チェックリストで判定してください。

【判定対象】
{ここに対象のテキスト・台本・コピーを貼る}

【出力形式】
1. 判定（OK / 修正必要 / NG）
2. 該当箇所と理由（NG/修正必要の場合）
3. 修正案（あれば）
4. 軽微な提案（推奨）
```

## 2. チェックリスト（v1）

### 2-1. 法令カテゴリ

#### 薬機法
- [ ] 「治る」「治癒」「改善する」「予防する」など医薬品的効能効果の断定がないか
- [ ] 「白髪が黒くなる」「白髪が消える」「白髪を増やさない」がないか
- [ ] 化粧品/医薬部外品の効果を超えた表現がないか

#### 景表法
- [ ] 「絶対」「100%」「完璧」「必ず」など断定的優良誤認表現がないか
- [ ] 「業界No.1」「日本一」など根拠のない優位性主張がないか
- [ ] 「今だけ」「限定」「先着」など不当な有利誤認がないか
- [ ] 「全額返金」「効果なければ返金」など実際の運用と矛盾する保証がないか
- [ ] 比較広告で他社を貶める表現がないか

#### 特商法
- [ ] 月額料金が明示されているか
- [ ] 解約条件が明示されているか
- [ ] 自動更新の説明があるか
- [ ] 事業者名・連絡先のリンクがあるか

#### 個人情報保護法（PIPA）
- [ ] 顧客の写真・実名・実例を出す場合、本人同意が確認できるか
- [ ] 「お客様の声」が改変・誇張されていないか

#### LINE公式アカウント規約
- [ ] 過度なpushがないか（24時間で2通超など）
- [ ] スパム的・連投的でないか

### 2-2. ブランド・トーン

#### 川崎さんの権威性
- [ ] 「20年」「何万人」「大阪専門店」「海外経験」のうち最低1つが含まれているか（必須コンテンツのみ）

#### POSITIONING-FINAL.md §11 の7コアメッセージ
- [ ] 「気になるところだけ」と矛盾しないか
- [ ] 「プロ用商材」を市販品より下とする表現になっていないか
- [ ] 「頭皮ケアまで伴走」のメッセージを毀損しないか
- [ ] 「染める/染めない両方アリ」と矛盾しないか（「染めない美容師」スタンスに寄りすぎていないか）
- [ ] 「月880円・解約自由」が明示されているか（広告/LP）
- [ ] 「商材購入は任意」が明示されているか（広告/LP）

#### トーン
- [ ] 上から目線（「教えます」「指導します」）になっていないか
- [ ] 不安煽り（「放っておくと危険」「手遅れ」）がないか
- [ ] 営業色強すぎ（「お得」「特別」を多用）がないか
- [ ] 競合誹謗（coloris等への直接攻撃）がないか

### 2-3. 表現の置き換え

NG → OK の置き換えチェック：

| NG | OK |
|---|---|
| 染まります | 染まりやすい設計です |
| 全額返金 | いつでも解約できます |
| アレルギー安心 | アレルギー履歴のある方の相談を受けています |
| 美容室不要 | 美容室の合間に、自宅での選択肢として |
| 治る | 改善が期待されます／実感される方が多いです |
| 絶対失敗しない | 失敗しにくいコツをお伝えします |
| 「全員」 | 「多くの方」 |
| 「証明された」 | 「確認されています」 |

### 2-4. 数字・統計の扱い

- [ ] 数字を出す場合、「個人差があります」を添えているか
- [ ] 統計データに出典があるか
- [ ] 「カラーリスト20年」など、客観的に検証可能な事実か
- [ ] 「何万人のカラー経験」は「数万人」または「累計◯人」と置き換え可能か（概算でも事実ベース）

### 2-5. 医療領域への配慮

- [ ] アレルギー・頭皮トラブルの話題で「医師の判断を尊重」が添えられているか
- [ ] 妊娠中・授乳中の話題で医師相談を促しているか
- [ ] 自社で医学的判断をしている印象を与えていないか

## 3. 判定基準

| 判定 | 条件 |
|---|---|
| **OK** | チェックリスト全項目クリア、修正不要 |
| **修正必要** | 1〜2項目で警告（NG表現1つあり等）、提示の修正案で軽微に直せる |
| **NG** | 3項目以上で警告、または法令違反確実な表現あり、出稿不可 |

---

## 4. 出力例

### 例1：OK
```
判定: ✅ OK

該当箇所と理由: なし

修正案: なし

軽微な提案:
- 「気になるところだけ」の文言を冒頭2秒以内に出すと、コアメッセージが強化される
```

### 例2：修正必要
```
判定: ⚠ 修正必要

該当箇所と理由:
- 行3「絶対染まります」→ 景表法上の断定的優良誤認
- 行5「アレルギーでも安心」→ 薬機法上のリスク

修正案:
- 「絶対染まります」→「染まりやすい薬剤を選んでいます」
- 「アレルギーでも安心」→「アレルギー履歴のある方の相談を受けています」

軽微な提案:
- 月額料金の表示が下部のみ。冒頭でも触れると特商法強化
```

### 例3：NG
```
判定: ❌ NG

該当箇所と理由:
- 行1「白髪が確実に黒くなります」→ 薬機法重大違反、医薬品的効能効果断定
- 行7「全額返金保証」→ 実際の運用と矛盾、特商法不当表示
- 行10「業界No.1のサービス」→ 景表法、根拠なし優良誤認

修正案:
出稿不可、台本から作り直し推奨。

軽微な提案: なし（やり直し前提）
```

---

## 5. 運用ルール

- E判定は**全広告・全LP・全SNS投稿で必須**
- E判定をスキップした出力は管理者LINEへ送らない
- E判定 NG が出た出力は、修正してEを再通過させない限り承認キューに乗せない
- ユーザーが「Eを無視して通す」と明示指示した場合のみ、Eスキップの記録を残して通す
