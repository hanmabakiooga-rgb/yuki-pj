## Pattern V1：「川崎さん前面・信頼設計」

### 構造
1. **FV：川崎さんの実写 + 一言**
   ```
   [川崎さんの大きな写真、サロン背景]
   
   "気になるところだけでいい"
   
   現役カラーリスト20年・大阪専門店経営
   数万人の白髪と向き合ってきた私が、
   LINEで毎月伴走します。
   
   [ LINEで相談スタート ]
   月880円 / いつでも解約OK
   ```

2. **「私のことを少し」セクション**
   - 経歴タイムライン（20年の流れ）
   - 海外経験のエピソード
   - 大阪のサロンの様子（写真2-3枚）
   - 受賞・メディア露出があれば

3. **「私が一緒にやること」3カード**
   - 染める・染めない判断
   - プロ用商材の提案
   - 染めた後の頭皮ケア

4. **不安への先回り Q&A 5問**
   - 「自分で染めるの怖いです」→ 川崎さんの返答コメント
   - 「アレルギー出ました」→ 同
   - 「失敗したらどうなりますか」→ 同
   - 「商材買わないとダメ？」→ 同
   - 「合わなかったら？」→ 同

5. **利用者の声（実名NG、年代+職業）**

6. **料金（透明性）**

7. **LINE登録の流れ**

8. **FAQ + 特商法**

### 狙う層
- 「人を信頼してから決めたい」感情派
- 川崎さん個人のキャラクターで惹きつける
- インスタ広告経由で来た人（人物画像が広告から続く）

### 想定CVR
- 35-42%（人物への信頼が決定打になる層に強い）

### 視覚要素
- メイン色：**ベージュ＋ダークブラウン**（落ち着き・専門性）
- 写真比率高め（川崎さん、サロン内、施術中）
- イラストは最小限、実写中心

## Pattern V2：「不安に全振り・寄り添い設計」

### 構造
1. **FV：質問形式の共感フック**
   ```
   [優しいベージュ背景、淡いイラスト]
   
   「分け目の白髪、気になるのに、
    また美容室？市販剤？セルフ？」
   
   迷ってる気持ちを、まず聞かせてください。
   
   [ LINEで気軽に相談 ]
   どんな質問でもOK / 月880円 / 解約自由
   ```

2. **「同じ気持ちの方、たくさんいます」**
   - よくある不安7つ、それぞれに「FOLLOWではこう答えます」
     - 自分で染めるの怖い → 「初回は塗らない相談だけでもOK」
     - アレルギーが心配 → 「ジアミンフリーの選択肢、医師連携の運用」
     - 失敗したらどうしよう → 「写真を送ってもらいながら一緒に進めます」
     - 美容室に行く時間がない → 「LINEで完結、自分のペースで」
     - お金をかけたくない → 「年間で67,250円の差、商材も任意」
     - "染めない選択"も悪い気がする → 「染めない月もアリ、両方サポート」
     - 続けられるか不安 → 「いつでも解約OK、お試し感覚で大丈夫」

3. **川崎さん紹介（コンパクト）**
   - 写真1枚 + 経歴3行 + 一言「あなたの気持ちに寄り添います」

4. **「やらないこと」リスト（誠実開示）**
   - 全頭染めの強制
   - 商材の押し売り
   - 効果の保証
   - 美容室をやめさせること
   - 「絶対」「100%」みたいな約束

5. **料金 + 解約方法**

6. **LINE登録の流れ**

7. **FAQ**

### 狙う層
- 不安が強くて踏み出せない層
- 「決断疲れ」している人
- 過去にセルフカラーで失敗経験あり

### 想定CVR
- 32-40%（不安解消が刺さる層に強い、決断疲れに寄り添う）

### 視覚要素
- メイン色：**淡いピンクベージュ＋ホワイト**（柔らかさ）
- 文字が多め、空白を活かして"読みやすさ"
- イラストは表情のあるもの（不安・安心・笑顔の対比）

## Pattern V3：「ビフォーアフター・ストーリー設計」

### 構造
1. **FV：1顧客の半年ストーリー**
   ```
   [Aさん（45歳・実例 or 同意済み）の6ヶ月ビフォーアフター 大写真]
   
   全頭染めをやめて6ヶ月。
   気になるところだけ整えるって、こういうことです。
   
   ― Aさん（40代・会社員）
   
   [ LINEで相談スタート ]
   ```

2. **「Aさんの6ヶ月」ストーリー（タイムライン）**
   - 1ヶ月目：初回相談、分け目だけリタッチ
   - 2ヶ月目：頭皮ケア追加、染めない週を作る
   - 3ヶ月目：プロ用商材に切替、塗布時間半減
   - 4ヶ月目：美容室の予約頻度が下がる
   - 5ヶ月目：頭皮の調子が良くなる
   - 6ヶ月目：時間とコストの実感

   各月の LINE 画面風キャプチャ（モック）

3. **他の利用者の声（3-5名）**
   - 30代・育児中
   - 40代・働く女性
   - 50代・敏感肌

4. **川崎さん紹介**
   - 写真 + 経歴 + 「一人ひとりにストーリーがある」

5. **「あなたの6ヶ月を一緒に作ります」CTA**

6. **料金・FAQ・特商法**

### 狙う層
- ビジュアル先行で決断する層
- 「結果が見えないと動けない」層
- Reels/Instagram からの流入と相性◎

### 想定CVR
- 38-45%（社会的証明が最強の説得材料）

### 視覚要素
- メイン色：**温かみのあるアイボリー＋アクセントオレンジ**
- 写真比率最大（実例ビフォーアフター必須）
- タイムライン視覚化（縦スクロールで6ヶ月の流れ）

## A/Bテストの設計

### 振り分け方法
- 広告から流入時に均等4分割（V0/V1/V2/V3）
- UTM パラメータ `lp_variant=v0/v1/v2/v3` で識別
- D1 `lp_variant_visits` テーブルで計測

### KPI
- LP→LINE登録CVR（メイン）
- LP滞在時間
- スクロール深度
- LINE登録後の課金CVR（後段の質も見る）

### 期間
- 4週間（最短）
- 各バリアント 100訪問以上で判定

### 勝敗
- 勝ち：CVRが他3つを統計的有意に上回る（+5pt以上）
- 引き分け：3つ以上が同水準なら、CVRランキング上位2つで決勝戦

## 不安解消の言葉ライブラリ（全バリアント共通）

A/Cの広告台本、SNS投稿でも再利用：

| 不安 | 寄り添う言葉（OK）| 避ける言葉（NG）|
|---|---|---|
| 自分で染めるの怖い | 「初回は塗らない相談だけでもOK」 | 「絶対失敗しません」 |
| アレルギーが出る | 「医師の判断と並行で運用相談します」 | 「アレルギー安心」 |
| 失敗したらどうしよう | 「写真を見ながら一緒に進めます」 | 「100%きれいに染まります」 |
| 美容室に行きたい | 「やめなくて大丈夫、間を埋めるサービスです」 | 「美容室不要」 |
| 「染めない」は変かな | 「染めない選択も応援します」 | 「染めない方が良い」（押し付け）|
| 商材買いたくない | 「購入は完全任意、他で買ってもOK」 | 「これがおすすめ」（強要的）|
| 続けられない | 「いつでも解約OK、お試し感覚で」 | 「3ヶ月は続けてください」 |

## デザイン共通方針（V1〜V3で守る）

### タイポグラフィ
- 見出し：游ゴシック or Noto Sans JP 太字
- 本文：游ゴシック / 16px / 行間1.8
- 強調：オレンジ系アクセント色

### 配色（パターン別）
- V1：ベージュ＋ダークブラウン（権威・落ち着き）
- V2：淡ピンクベージュ＋ホワイト（柔らかさ）
- V3：アイボリー＋アクセントオレンジ（温かみ）

### モバイル最優先
- 全パターンとも縦長スクロール前提
- ボタンは横幅100%
- 文字サイズ最小14px
- タップ領域 44px以上

### LINE登録ボタン
- LINEブランド緑 (#06C755)
- ファーストビュー、中間2箇所、フッターの最低4箇所
- スティッキー（スクロールしてもCTAが消えない）も検討
