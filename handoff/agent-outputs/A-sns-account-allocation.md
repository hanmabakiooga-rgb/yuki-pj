## 運用上の注意

### 1. FOLLOW公式 Threads の生成タイミング
- 毎晩 23:00 に翌日3投稿分を A が生成
- E 法務チェック自動実行 → 合格分のみ sns_queue D1 に「scheduled」保存
- Workers Cron が朝7:30 / 昼12:30 / 夜21:00 に Threads API 投稿
- 管理者LINEへ「明日の3投稿」サマリーが届く

### 2. HEJ Threads は手動 or 半自動
- 川崎さん本人レビュー or AI下書き→確認後投稿
- FOLLOW誘導が必要な日（月水金日）はLINK or プロフ誘導表現を必ず入れる

### 3. Reels 1本→2本書き出し
- Vrew/CapCut で本編生成
- 末尾2秒だけ差し替えて HEJ用 / FOLLOW公式用 を別ファイル化
- HEJ用：「20年カラーリストが教える本音」冒頭／「DMで質問OK / プロフリンクからFOLLOW」末尾
- FOLLOW公式用：「分け目だけ、染めればいい」冒頭／「月880円・写真送るだけ・プロフのLINEから」末尾

### 4. note は HEJ プロフから誘導
- HEJ プロフィール末尾に最新note URL を貼る運用
- 川崎個人の編集レビュー必須

### 5. 「新規生成」フラグの取り扱い
- 表中で「新規生成・既存スタイル準拠」と明記したFOLLOW公式昼/朝スロットは、既存バックログだけでは3スロット×7日が埋まらない箇所
- A エージェントは既存バックログのトーン・コアメッセージを継承して生成
- E 法務チェック必須（全文）
