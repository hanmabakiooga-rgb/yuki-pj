## 1. 全体フロー

```
顧客からLINEメッセージ着信
        │
        ▼
① 営業時間チェック
  ├─ 時間外 → テンプレ 2-12「営業時間外」自動応答 → 終了
  └─ 時間内 → ②へ
        │
        ▼
② 顧客ステータス判定（D1 から取得）
  ├─ NEW（LINE登録後、カウンセリング未完了）→ テンプレ 2-1「初回登録」
  ├─ COUNSELING_DONE（カウンセリング完了）→ ③へ
  ├─ PAYING（課金中）→ ③へ
  └─ PAUSED（休止中）→ ④「休止中顧客」へ
        │
        ▼
③ メッセージ種別判定
  ├─ 画像（写真）→ テンプレ 2-4「染め方相談」+ 写真受領確認
  ├─ キーワード「解約」「やめたい」「退会」→ テンプレ 2-6「解約申し出」
  ├─ キーワード「アレルギー」「かゆい」「かぶれ」「腫れ」「痛い」→ テンプレ 2-5「アレルギー」
  ├─ キーワード「紹介」「友達に教えたい」→ テンプレ 2-8「紹介依頼」
  ├─ キーワード「他で買った」「別の商材」「自分で買った」→ テンプレ 2-9「他購入OK」
  ├─ キーワード「染めない」「今月は休む」「お休みしたい」→ テンプレ 2-11「染めない月」
  └─ その他テキスト → ⑤ B エージェントが内容判断
        │
        ▼
⑤ B エージェント判断（AIで意図分類）
  ├─ 染め方・技術的質問 → テンプレ 2-4「染め方相談」ベースに生成
  ├─ 雑談・お礼・報告 → テンプレ 2-10「雑談」ベースに生成
  ├─ 初回課金前の迷い → テンプレ 2-3「初回課金後押し」
  └─ 判断困難・複雑 → 川崎さんへエスカレ（未読フラグ + Flex通知）
```

## 2. 営業時間外ロジック詳細

```
JST で判定（Cloudflare Workers の Date.now() + UTC+9）

時間内: 平日（月〜金）09:00-19:00
時間外: 上記以外

緊急ワード（時間外でも即エスカレ）:
  "頭皮 痛い", "腫れた", "アレルギー 出た",
  "目に入った", "血", "救急", "病院"

  → テンプレ 2-5「アレルギー」+ J-emergency-handler を発火
  → ユーザーLINEへ警告Flex送信
```

## 3. 顧客ステータス定義

```sql
-- D1 customers テーブルの status カラム
status = 'new'              -- LINE登録直後、カウンセリング未回答
status = 'counseling_done'  -- カウンセリング回答済、課金前
status = 'paying'           -- Stripe サブスク active
status = 'paused'           -- Stripe サブスク paused（課金停止中）
status = 'cancelled'        -- 解約済（履歴保持）
```

## 4. テンプレ選択マッピング

| 着信パターン | 採用テンプレ | 自動送信 | 川崎さんレビュー |
|---|---|---|---|
| 時間外（非緊急） | 2-12 | ✅ 自動 | 不要 |
| 時間外（緊急ワード） | 2-5 + エスカレ | ✅ 自動 | 即通知 |
| NEW + テキスト | 2-1 | ✅ 自動 | 不要 |
| 写真送信 | 2-4（写真受領確認） | ✅ 自動 | 川崎さんが詳細返信 |
| 「解約」ワード | 2-6 | ⏸ 川崎さん確認後 | **必須** |
| 「アレルギー」ワード | 2-5 | ✅ 自動（医療注記） | 川崎さんフォロー |
| 「紹介」ワード | 2-8 | ⏸ 川崎さん確認後 | **必須** |
| 「染めない」ワード | 2-11 | ✅ 自動 | 不要 |
| 「他購入」ワード | 2-9 | ✅ 自動 | 不要 |
| 雑談・お礼 | 2-10 | ⏸ B生成→川崎さん確認 | 推奨 |
| 複雑な技術相談 | エスカレ | - | **必須** |
| 判断困難 | エスカレ | - | **必須** |

## 5. エスカレーション仕様

### 川崎さんへのエスカレ Flex（管理者LINE）

```json
{
  "type": "bubble",
  "header": {
    "contents": [{"text": "⚠ 対応待ち", "color": "#FF6B35"}]
  },
  "body": {
    "contents": [
      {"text": "顧客: {customer_name}"},
      {"text": "内容: {message_preview}"},
      {"text": "ステータス: {customer_status}"},
      {"text": "着信時刻: {timestamp}"}
    ]
  },
  "footer": {
    "contents": [
      {"type": "button", "label": "LINEを開く", "action": {"type": "uri", "uri": "{line_chat_url}"}},
      {"type": "button", "label": "B に任せる", "action": {"type": "postback", "data": "delegate_to_b:{message_id}"}}
    ]
  }
}
```

「B に任せる」を押すと → B が自動生成した返信を自動送信。

## 6. 14日未返信フロー（H連携）

```
毎日 09:00 に D1 をスキャン:
  SELECT * FROM customers 
  WHERE last_customer_message_at < NOW() - INTERVAL '14 days'
    AND status = 'paying'
    AND escalated_14d = FALSE

→ 該当顧客にテンプレ 2-7「14日呼びかけ」を送信
→ escalated_14d = TRUE に更新
→ H エージェントにリスクスコア上昇を通知
```

## 7. 初回登録後の自動フロー

```
LINE登録（友だち追加）
  └─ 即時：テンプレ 2-1「初回登録挨拶」自動送信
        │
        ▼（24時間後、カウンセリング未完了の場合）
      リマインド：「カウンセリングフォームに回答いただくと、より具体的な提案ができます」
        │
        ▼（さらに72時間後も未完了）
      2回目リマインド：「いつでも大丈夫です。気が向いたときに教えてください ― 川崎」
        │
        ▼（7日後も未完了）
      H エージェントへ「カウンセリング未完了顧客」として通知
```
