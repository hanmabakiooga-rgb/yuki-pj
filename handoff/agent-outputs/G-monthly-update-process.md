# G実働：SNSインテリジェンス 月次更新プロセス設計

実行: エージェントG（SNSインテリジェンス）
作成日: 2026-06-12
状態: 運用設計確定版
前提: G-trend-report-2026-06-10.md / G-competitive-intel-2026-06-10.md が初回として完成済

---

## 1. Gエージェントの役割定義

SNSトレンド・競合動向を常時ウォッチして、A/C/Hの出力品質を維持・向上させる。

**月に1回の更新（毎月1日）** をデフォルトとし、  
異常検知（競合が新機能リリース・急騰キーワード出現）は随時。

---

## 2. 月次更新の構成（毎月1日、所要60分）

### 2-1. トレンドレポート更新（G-trend-report-YYYY-MM.md）

| 項目 | 収集方法 | 判断軸 |
|---|---|---|
| Instagram Reels トレンドキーワード | Meta Business Suite インサイト + 手動キュレーション | 前月比で浮上したワード |
| note / Twitter 白髪関連バズ記事 | 手動検索 + Googleトレンド | エンゲ1000以上 |
| セルフカラー検索トレンド | Google Search Console（LP） | 前月比+20%以上のクエリ |
| 季節トピック | 2ヶ月先の季節先取り | 6月→秋の準備、9月→冬の準備 |

**出力形式**：  
- ホット3ワード（A の Threads/Reels に即反映）  
- 季節先取りテーマ（A の次月バックログに渡す）  
- 注目SNS投稿フォーマット（縦型動画 / ツリー / カルーセル）

### 2-2. 競合インテリジェンス更新（G-competitive-intel-YYYY-MM.md）

**ウォッチ対象（優先）：**

| サービス | URL | ウォッチ方法 |
|---|---|---|
| coloris | coloris.jp | LP変化 / 料金変化 / SNS投稿頻度 |
| ハッピーマイル白髪ケア | happy-mile.jp | 同上 |
| ブランシェア | blanchear.jp | 同上 |
| 染めない美容師系アカウント（代表2〜3名）| Instagram | フォロワー増減 / 投稿テーマ |

**更新サイクル：**

```
毎月1日 09:00 に G が:
1. 上記4サービスの LP を確認（料金・訴求変化）
2. Instagram アカウントの直近10投稿を確認
3. 変化があれば G-competitive-intel-YYYY-MM.md に記録
4. 変化なしでも「変化なし確認」として記録（日付更新）
```

**差分サマリー形式**（毎月管理者LINEへ送信）：

```
🔷 G競合インテリ 2026-07

主な変化:
- coloris: 料金を¥1,650→¥1,980に値上げ（+20%）
  → 価格差が拡大、「月880円」の訴求をより強調できる

- 染めない美容師A: フォロワー 1.2万→1.4万（+16%）、
  Reels頻度が週2→週4に増加
  → 競合が加速中、FOLLOW も Reels 週4を検討

変化なし:
- ブランシェア、ハッピーマイル白髪ケア

今月の推奨アクション（A/C 向け）:
- coloris 値上げを逆手に「月880円の差」コンテンツを1本作る
- 「染めない vs 染めるどちらもアリ」の訴求を強化（染めない美容師との差別化）
```

## 3. 随時ウォッチ（月次以外）

以下の場合は即座に G-alert-YYYY-MM-DD.md を作成 → A/C に通知：

| トリガー | 対応 |
|---|---|
| 競合が大幅値下げ（-30%以上） | 価格ページ・訴求の見直し提案（E法務通してC/Aへ） |
| 競合がTVCM・大型PR | ポジショニング再確認 + 差別化強化提案 |
| 白髪・セルフカラー系ワードの急上昇（Googleトレンド） | A のバックログに緊急コンテンツ追加 |
| 薬機法・景表法の新ガイドライン | E に即通知 → 全コンテンツの再チェック |
| FOLLOWのSNS投稿がバズ（エンゲ通常の3倍以上） | G がバズ要因を分析 → A に横展開提案 |

## 4. FOLLOWのSNSパフォーマンス月次分析

毎月1日に Meta Business Suite から抽出：

| 指標 | 取得方法 | 目標値 |
|---|---|---|
| Reels 再生数（月次） | Meta Business Suite | 毎月+20%成長 |
| Reels フォロワー転換率 | (フォロワー増加) / (Reels再生数) | 2%以上 |
| Threads インプレッション | Meta Business Suite | 毎月+15%成長 |
| note ページビュー（月次） | note 管理画面 | 毎月+10%成長 |
| LP 流入（SNS経由）| Cloudflare Analytics + UTM | LP流入全体の30%以上 |

**分析レポート形式**（G-sns-performance-YYYY-MM.md）：

```
## 2026-06 SNSパフォーマンス

### Reels（4週16本）
- 平均再生: 1,200回（目標1,000回達成）
- 最高再生: D9「染め方5分」3,400回（勝因: 具体的手順 + 梅雨ネタ）
- 最低再生: D2「権威性」450回（要改善: 川崎さん顔出し比率を上げる）

### Threads（37投稿）
- 平均インプレ: 280
- 最高エンゲ: D15 ツリー「続かない人の共通点」→ 共感コメント12件
- フォロワー: +148名（目標+100名達成）

### note（3本）
- 合計PV: 2,150
- 最高PV: 第2回「美容室との付き合い方」1,400PV
- LINE誘導クリック: 38件（月間LINE登録の15%がnote経由）

### LP流入（SNS経由）
- Instagram → LP: 310セッション
- note → LP: 45セッション
- SNS経由LP訪問 合計: 355 / LP総訪問の28%（目標30%まであと少し）

### 来月へのアクション
- Reels の冒頭2秒を「川崎さん顔出し」に統一（再生維持率改善）
- noteの閲覧→LINE誘導のCTAを記事中盤にも追加
- Threads ツリー形式 を週2回→週3回に増やす
```
