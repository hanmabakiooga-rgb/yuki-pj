## 4. 弱い点（補強提案、優先度順）

### 🔴 優先1：川崎さんの権威性が完全に欠落

LP全体に「現役カラーリスト」としか書かれていない。**誰なのか分からない**。

POSITIONING-FINAL.md の確定事項：
- 現役カラーリスト20年
- 海外経験
- 何万人のカラー経験
- 大阪でカラー専門店10年以上経営

**→ 専用セクションを「写真から確認すること」の直後に挿入**

#### 挿入案

```
─────────────────────────
あなたの写真を見るのは、
この道20年のカラーリストです。

[川崎さんの写真（実写推奨、イラストでも可）]

・現役カラーリスト 20年
・大阪でカラー専門店を10年以上経営
・海外でのカラーリスト経験
・これまで数万人の白髪相談に対応

毎日サロンの現場に立ちながら、
LINEでの相談に答えています。

「染めるか、染めないか」から一緒に考える。
それが私のスタンスです。
― 川崎
─────────────────────────
```

期待効果：**CVR +3〜5pt**（信頼指標はLPの最重要要素のひとつ）

### 🟡 優先4：プロ用商材の表現確認（重要・ユーザー判断必要）

LPでは「薬剤単価 約300円」「ネットで買えるリンクを送信」とある。

**確認したいこと**：
- 提案している薬剤は「プロ用（美容師向け商材）」？それとも市販品も含む？
- POSITIONING-FINAL.md では「美容師が現場で使うプロ用商材」を強みとしている
- LPにその言葉がない → 「今の髪に合う薬剤」とだけある

**もしプロ用を提案しているなら**、LPに明記すべき：
```
「案内する薬剤は、美容師が現場で使うプロ用を中心に、
 あなたの髪と頭皮に合わせて選びます」
```

**もし市販品中心なら**、POSITIONING-FINAL.md の強み②の表現を調整する必要がある。
→ どちらが実態か、ユーザーに確認。

## 5. やらないこと（理由付き）

|---|---|
| ファーストビューのコピー変更 | 「染めに行くほどじゃない。でも、ここだけ気になる。」は完成形。触らない |
| 年間費用比較の数字いじり | 誠実な注記付きで現状ベスト |

| セクションの並べ替え | 現状の流れ（共感→解決→価格→誠実開示→FAQ）は王道で正しい |
| 「できないこと」セクションの縮小 | 一見ネガティブだが信頼構築に効いている。残す |
