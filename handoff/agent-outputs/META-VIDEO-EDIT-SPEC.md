## 6. Vrew での具体的操作手順

### 6-1. プロジェクト作成

1. Vrew起動 → 「新規プロジェクト」
2. アスペクト比: **9:16 (縦)** を選択
3. プロジェクト名: `follow_ad_2026-07_A` (バリエーションごとに分ける)

### 6-2. 台本入力 → AI音声 or 肉声インポート

**Var.A (ナレーション無し版がメイン)** :
- 台本テキストはテロップ用のメモのみ
- 「AI音声」OFF
- 動画素材 (ストック + 川崎さん素材 + LINE画面モック) を直接インポート

**Var.B (川崎さん肉声)** :
- 「ファイル → 動画/音声をインポート」で川崎さん収録素材 (KAWASAKI-SHOOT素材①②⑤) をD&D
- 必要部分だけ秒数指定でカット
- 「AI音声」OFF (肉声を使うため)

**Var.C (一部ナレーション)** :
- 川崎さんナレ部分は素材②抜粋を使う
- 川崎さん収録に無い部分は **AI音声 (Vrew内蔵「日本人女性ナチュラル」)** を使う

### 6-3. 自動字幕生成 → 修正

1. インポート完了 → 自動で文字起こしが走る
2. 画面下部に字幕がタイムライン化される
3. **修正ポイント** :
   - 「川崎」が「カワサキ」「川崎市」になっていないか確認
   - 「FOLLOW」が「フォロー」になっていないか確認
   - 「880円」が「八百八十円」になっていないか確認
   - 「ジアミン」「リタッチ」等の専門用語は手動修正必須
4. 字幕の改行を 1行15文字以内に手動調整

### 6-4. シーン分割・カット

1. タイムライン上でクリック → 「ここで分割」
2. 不要シーンを選択 → Delete
3. §2-2 / §3-2 / §4-3 のショットリスト通りに並び替え

## 7. CapCut での仕上げ手順

### 7-1. プロジェクト作成

1. CapCut起動 → 「新規プロジェクト」
2. アスペクト比: 9:16
3. Vrew書き出しの中間ファイルを D&D

### 7-2. BGM追加

1. 「音声 → 音楽」タブ
2. カテゴリ「Vlog」or「Lifestyle」から §2-4 / §3-5 / §4-6 の推奨曲を選択
3. 音量: -18dB
4. フェードイン 0.3秒 / フェードアウト 0.5秒

### 7-3. テロップ (§1-6 共通テロップガイドに従う)

1. 「テキスト」タブ → 「テキスト追加」
2. フォント・色・サイズを設定 (源ノ角ゴシック / 120pt / 白 / 黒縁3px)
3. 位置 (Y座標) を §1-6 配置ルール通りに
4. アニメ「ポップ」or「タイプライター」を選択

### 7-4. エフェクト (過剰演出はNG)

採用するもの:
- フェード / カット (基本)
- ホワイトフラッシュ 0.2秒 (Var.B 0:02 のみ)
- ポップイン (CTA テロップ)
- ズームイン 0.3秒 (Var.C 0:05 グラフ表示)

**使わないもの**:
- 派手な3Dトランジション
- グリッチ・ノイズエフェクト (信頼性が下がる)
- 強い色フィルター (川崎さんの顔色が変わる)

### 7-5. 末尾2秒の差し替えバージョン作成

1. 完成版プロジェクトを「複製」(右クリック → Duplicate)
2. 複製プロジェクト名: `follow_ad_2026-07_{variant}_official` (元は `_hej`)
3. タイムライン末尾 0:13-0:15 のテロップだけを §5-2 (FOLLOW公式用) に差し替え
4. アイコン素材 (DM/LINE) も差し替え
5. 書き出し

### 7-6. 9:16 と 1:1 の書き出し分岐

1. 9:16版が完成したら、再度プロジェクトを複製
2. 複製プロジェクト → 「プロジェクト設定 → アスペクト比 → 1:1」に変更
3. テロップ位置を §5-4 通りに手調整 (CapCut は自動再配置しないため必須)
4. 書き出し

### 7-7. サムネイル静止画書き出し

1. タイムラインで「冒頭2秒以内のフックが最も強い瞬間」を選ぶ (Var.A: テロップ「分け目、月3回は気になる」表示中、Var.B: 川崎さんバストアップ、Var.C: 「美容室 vs FOLLOW」表示中)
2. 「フレーム書き出し」→ JPG quality 90
3. ファイル名: `follow_ad_2026-07_{variant}_thumb.jpg`

### 7-8. CapCut 書き出し設定 (再掲)

形式: MP4 (H.264)

## 9. 法務E最終チェックリスト (各バリエーション別)

### 共通チェック (3バリエーション全部に適用)

- [ ] **「染まる」「絶対」「100%」「完全」「治る」等の断定が一切ないか** (映像テロップ・ナレ・キャプション・説明文すべて)
- [ ] **医療系言及がないか** (「治療」「薬」「副作用」「効能」等)
- [ ] **押し付け表現がないか** (「やめるべき」「これしかない」「絶対やった方がいい」等)
- [ ] **競合誹謗がないか** (美容室・他社サブスクを直接けなしていないか)
- [ ] **価格表記が正確か: 月880円 (税込)**
- [ ] **「商材代は別途実費」が補助テロップorキャプションに入っているか** (POSITIONING §4 整合)
- [ ] **紹介特典は「1ヶ月無料」のみ、金銭表示なし** (本動画では紹介特典には触れない予定だが、もし触れる場合は「1ヶ月無料」のみ)
- [ ] **川崎さん肖像権の使用許諾が取れているか** (撮影時にビフォーアフター同意書とセットで取得済か社内チェック)
- [ ] **「いつでも解約OK」が明示されているか**
- [ ] **LP着地 → LINE登録のCTAが明確か**

### バリエーション A 個別

- [ ] 冒頭2秒「分け目、月3回は気になる」が共感の範囲内か (脅し・煽りすぎ表現でないか)
- [ ] 「気になるところ "だけ" 染める」が POSITIONING §2 強み① と整合しているか
- [ ] LINE通知音は使っていないか (商標リスク回避)
- [ ] BGM が CC0扱いの CapCut公式素材ライブラリ内のものか

### バリエーション B 個別

- [ ] 川崎さん権威性「20年・海外・大阪専門店」が POSITIONING §1-D と整合しているか
- [ ] 「現役カラーリスト 20年」の数字が事実か (川崎さん本人確認済か)
- [ ] 「何万人」の数字を使う場合は「およそ」「これまで」等の幅を持たせた表現になっているか
- [ ] 川崎さん本人のカメラ目線素材使用について、本人OKを取得済か

### バリエーション C 個別

- [ ] 比較データ「年間 約 ¥67,250 の差」が LP-V2 §4-9 と完全一致しているか
- [ ] 「約」を必ず付けているか (断定回避)
- [ ] 美容室を貶める表現がないか (「高い・遅い」等の主観でなく、価格・時間の事実のみ)
- [ ] 「サロンと自宅の、その間を埋めます」表現が POSITIONING §1-B と整合しているか
- [ ] 「商材代は別途実費」の補助テロップが入っているか (年間費用差を語る上で必須)

### 入稿前最終チェック (Meta広告マネージャ)

- [ ] プレビューでスマホ表示・テロップが読めるか
- [ ] LP URL タップで正しく開くか
- [ ] LP ファーストビューに「月880円」が表示されているか
- [ ] HEJ用と FOLLOW公式用、書き出し末尾2秒のCTAが正しく差し替わっているか
- [ ] サムネイル静止画が指定通り (自動生成ではなく手動アップロード) か
- [ ] UTM がバリエーションごとに正しいか (adA/adB/adC)
