## 6. 返信対応チートシート（24時間以内）

### A：「紹介したい」
→ 紹介リンク発行（H-referral-program-v2.md）。リンク未実装の間は：

```
ありがとうございます！
お知り合いに私のLINEを教えてあげてください。
「{name}さんの紹介」と一言添えてもらえれば、すぐにお二人とも1ヶ月無料の処理をします。
```

### B：写真が送られてきた
→ 通常の相談フロー（48時間以内に対応）
→ 対応後、H側でその顧客のリスクスコアを下げる

### C：「お休みしたい」
→ 課金停止＋以下返信：

```
承知しました。本日付で課金を一時停止します。
データはそのまま残しておきますので、戻りたくなったらいつでも声をかけてください。
こちらから30日後に「調子どうですか？」と1回だけ連絡しますね。
```

→ Stripe の pause 機能 or 手動キャンセル+メモ

### C：「解約したい」
→ 引き留めは **1回だけ**：

```
承知しました。差し支えなければ、合わなかった理由を一言だけお聞きしてもいいですか？
今後の改善に活かしたいです。
（言いにくければ「特になし」でも大丈夫です）
```

→ 解約処理 + 感謝メッセージ：

```
ありがとうございました。データは残しておくので、
いつでも戻ってきてください。それまでお元気で。
― 川崎
```

### 全グループ：返信なし
→ **追撃しない**。次の接触は1ヶ月後の季節ネタまで空ける。
