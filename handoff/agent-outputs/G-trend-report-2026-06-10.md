## 1. Instagram Reels（2026-06時点）

### 直近6ヶ月の変化
- 評価指標が「閲覧数（Views）」に統一
- **シェア（送信）が最重要シグナル**化、いいねは補助
- 2025-12 よりハッシュタグ上限**5個**
- 2026-05 転載系アグリゲーターへの制限強化

### 30〜50代女性に効くパターン
- **60〜90秒の教育系リール**
- 冒頭2秒で「年代＋悩み」（例：「40代の白髪、染め直し早すぎ問題」）
- 視聴維持率の獲得に直結

### 美容・ヘアケアの成功事例
- キャプション冒頭に**属性明記**（例：「元美容部員の頭皮ケア」）
- 「問いかけ → ハウツー → 保存誘導」の型
- あいり氏（48歳）「1分メイクチャレンジ」型が共感獲得

### 避けるべき
- 20個以上のタグ
- 毎投稿で同一タグ
- 転載／無断使用素材
- リプライ無視（シャドウバン要因）

## 2. Threads（2026-06時点）

### 直近6ヶ月の変化
- **リプライ由来インプレッションが全体の約50%**
- Meta公式は週**2〜5投稿**を推奨
- 「会話の広場」設計が鮮明化

### 30〜50代女性に効くパターン
- 1日1〜2回、**朝7時／夜21時**
- 「悩み共感 → 自己開示 → 問いかけ」3連ツリー

### 美容・ヘアケアの成功事例
- 「セルフカラーで失敗した話」など**弱み開示型**がリプライを誘発
- リプライがリーチを倍増

### 避けるべき
- 宣伝直球
- 外部リンクのみ投稿
- リプライ放置（会話シグナル消失 → リーチ減）

---

## 3. note（2026-06時点）

### 直近6ヶ月の変化
- おすすめロジックがパーソナライズ強化
- **タイトル＋タグで SEO の9割が決まる**

### 30〜50代女性に効くパターン
- 「タイトル → リード → 目次 → 本文」の定型
- **毎週同曜日・同時刻の固定投稿**でリピーター化

### 美容・ヘアケアの成功事例
- 「#日記」「#エッセイ」＋専門タグ併用
- **体験談 + 具体的手順**の混合構成

### 避けるべき
- 不定期投稿
- 汎用タグのみ
- AI生成丸出しの薄い記事（おすすめ枠から除外）

## 4. FOLLOWへの推奨アクション3つ

### ① Reels「失敗回避ハウツー60秒」シリーズ化
- 冒頭2秒：「40代のセルフカラー、●●だけはNG」
- 構成：結論先出し → LINE誘導
- **シェア最大化を狙う**（=2026のReels最重要シグナル）

### ② Threads「セルフカラー駆け込み相談」ツリー運用
- 週3本、朝7時 or 夜21時
- 構成：悩み開示 → FOLLOW会員の解決例 → 「あなたはどう？」で会話喚起
- リプライを必ず24時間以内に返す運用ルール

### ③ note 毎週水曜21時「880円で美容師に聞ける生活」連載
- 体験談 + ビフォーアフター写真
- 固定リズム（毎週水曜21:00）
- サブスクLPへの動線を最終段落に固定

## 5. Aへの指示事項（運用更新）

`AGENTS-SPEC.md` のエージェントA仕様を、このGレポートを反映して更新する：

### 変更点
- Reelsの推奨長さ：「15〜60秒」→**「60〜90秒」**
- Reelsの推奨ハッシュタグ数：「8〜12個」→**「最大5個」**
- Reels冒頭：「フック0:00-0:03」→**「年代＋悩みを冒頭2秒で明示」**
- Threadsの推奨頻度：「日3〜5回」→**「日1〜2回（週2〜5投稿）」**
- Threadsの推奨時間帯：「7:30-8:30 / 21:00-22:30」→**「朝7時 / 夜21時」**
- noteの推奨：**「毎週水曜21時の固定投稿」**

### 出力指示
- Reels台本の**最重要KPIは「シェア数」**（いいねではない）
- Threadsは**会話誘発が目的**（CTAは控えめ、最終投稿のみ）
- note は **AI感を消す**ことが重要、体験談ベース必須
