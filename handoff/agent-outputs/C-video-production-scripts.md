## 共通仕様（3本すべて）

### 動画スペック
| 項目 | 設定値 |
|---|---|
| アスペクト比 | **9:16（縦型）** |
| 解像度 | **1080 × 1920px** |
| フレームレート | **30fps** |
| 動画長 | **15〜30秒**（Reels最適） |
| ファイル形式 | **MP4（H.264）** |
| ビットレート | **8〜12 Mbps**（CapCutで「推奨」を選択） |
| 音声 | AAC 128kbps ステレオ |
| ファイルサイズ目標 | 50MB以下 |

### CapCut Pro 書き出し設定（共通）
```
解像度: 1080p
フレームレート: 30
コードレート（ビットレート）: 推奨
形式: MP4
スマートHDR: OFF
```

### フォント・色・サイズ（共通ブランドガイド）

| 用途 | フォント | サイズ | 色 | 縁取り |
|---|---|---|---|---|
| メインテロップ（大） | **源ノ角ゴシック Heavy**（CapCut内「Source Han Sans Heavy」） | **120pt** | #FFFFFF（白） | #000000 黒縁3px |
| サブテロップ（中） | 源ノ角ゴシック Bold | **72pt** | #FFFFFF | #000000 黒縁2px |
| キャプション字幕（小） | 源ノ角ゴシック Medium | **54pt** | #FFFFFF | 黒半透明背景BOX |
| 権威性テロップ | 源ノ角ゴシック Bold | **60pt** | #FFE600（黄）※強調色 | #000000 黒縁2px |
| CTA・価格 | 源ノ角ゴシック Heavy | **100pt** | #FFFFFF on #FF5050（赤背景BOX） | なし |

**フォント代替**：Source Han Sans が無ければ「Noto Sans JP Black」「ヒラギノ角ゴ W7」でOK。

### テロップ配置ルール
- **画面下から上1/3まで** がテロップ可動域（上1/3は顔・主要素材）
- 左右マージン **80px** ずつ確保
- 1行 **最大15文字**、超えたら改行

### BGM 共通方針
- CapCut Pro 内「**おすすめ**」→「**Vlog / Lifestyle**」カテゴリ
- 音量：BGM **-18dB**、ナレーション **-6dB**（声優先）
- フェードイン 0.3秒 / フェードアウト 0.5秒（書き出し前に必ず設定）

# 全3本共通：制作手順（編集者向けステップバイステップ）

## Step 1: Vrewで字幕生成（各動画 10分）

1. Vrew を開く → **新規プロジェクト** → 9:16 縦型を選択
2. 川崎さん収録動画を該当部分だけインポート
3. **AI字幕生成** をクリック（音声から自動文字起こし）
4. 字幕の誤字を修正（特に「FOLLOW」「880円」「カラーリスト」）
5. 不要部分（「えーと」「あの」等）をカット
6. **MP4でエクスポート**（一旦字幕付き素材として保存）

## Step 2: CapCut Proで仕上げ（各動画 30分）

1. CapCut Pro → 新規プロジェクト → **9:16** 選択
2. Step1のVrew出力 + ストック素材を順番にタイムラインへ
3. 上記「カット割り」表の通りに並べる
4. **テロップA〜F** を各タイミングで追加（フォント・色・位置は指定通り）
5. **BGM** を追加（指定曲）、音量調整（BGM -18dB / 声 -6dB）
6. **トランジション** を該当箇所に追加
7. プレビュー → 文字が読めるか、音が割れていないかチェック
8. **書き出し設定**：1080p / 30fps / 推奨ビットレート / MP4
9. ファイル名を `FOLLOW_adXX_xxxx_v1.mp4` に変更して保存

## Step 3: 入稿前チェック（C-meta-ads-checklist.md と照合）

- [ ] 9:16 縦型
- [ ] 15〜30秒以内
- [ ] 冒頭2秒でフック（テロップA）
- [ ] 権威性（テロップC）が必ず入っている
- [ ] 月880円・解約OK の文言（テロップF）
- [ ] LINE誘導のCTA
- [ ] 法務NGワード（「絶対」「100%」「治る」「美容室不要」）なし

# トラブル対処

| 症状 | 対処 |
|---|---|
| 川崎さん素材が暗い | CapCut「調整」→「明るさ +15」「コントラスト +10」 |
| 音声が小さい | CapCut「オーディオ」→「音量 +6dB」 |
| テロップが画面外 | Y座標を50pxずつ内側に動かす |
