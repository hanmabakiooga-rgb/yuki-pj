## 台本①「ハイライト伸び後の救済」（最有力・空白攻め）

### 狙い
- 競合（coloris/ホーユー）が抑えていない**最大の空白市場**を直撃
- AWA調査で「伸びたら結局セルフ白髪染め」が1位 → 痛みが明確

### 台本（72秒）

```
[0-3秒] 大テキスト：
「サロンのハイライト、6週間後どうしてる？」
→ 後頭部のアップ、伸びた根元が見える映像

[3-15秒] 共感パンチ
- ナレ：「美容室で1万5千円かけて入れたハイライト」
- カット：明るい根元 → 暗い伸びてきた部分の対比
- テキスト：「次のサロン、3ヶ月先まで予約取れない」

[15-35秒] 問題提起
- ナレ：「セルフ白髪染めだと、ハイライトが消える」
- カット：染めて全部茶色に → がっかり顔
- テキスト：「あの透明感、消したくない」

[35-55秒] 解決提示
- 川崎さん（カラーリスト）登場
- ナレ：「FOLLOWは"ハイライトを残してリタッチ"を、LINEで個別相談」
- カット：LINEチャット画面 → 「分け目だけ塗る場所」を図解
- テキスト：「あなたの髪の写真を見て、塗る場所だけ指示します」

[55-70秒] 信頼指標
- 大テキスト：「月880円、いつでも解約OK」
- 川崎さん笑顔
- ナレ：「サロンと、自宅の、その間を埋めます」

[70-72秒] CTA
- 大テキスト：「プロフから3秒で相談スタート」
- LINE アイコン
```

### キャプション
```
サロンのハイライト、伸びた後どうしてる？

FOLLOWは"ハイライトを残してリタッチ"の個別相談。
月880円、解約は自由。

「染める場所だけ」をLINEで毎回提案します。

▶ プロフのリンクから相談開始

#セルフカラー #ハイライト #白髪ぼかし #リタッチ #分け目
```

### KPI想定
- CTR：2.0%
- CV率（LINE登録）：5%
- CPA：¥1,200

## 台本②「染めるか、染めないか、一緒に決める」（グレイヘア移行軸）

### 狙い
- 50代の新興ニーズ「グレイヘア移行」を抑える
- 朝倉真弓系のフォロワー層に刺さる

### 台本（68秒）

```
[0-3秒] 大テキスト：
「50代、染めるか、やめるか、迷ってる人へ」
→ 鏡を見る女性の後ろ姿

[3-15秒] 共感
- ナレ：「白髪を染め続けるか、グレイヘアに移行するか」
- カット：白髪の生え際クローズアップ
- テキスト：「どっちが正解か、誰も教えてくれない」

[15-35秒] 問題提起
- ナレ：「美容師は染めることを前提に話す」
- カット：美容室の様子
- ナレ：「グレイヘア派のブログは、移行成功者しか語らない」
- カット：SNSのスクロール

[35-55秒] 解決提示
- 川崎さん登場
- ナレ：「FOLLOWは"染める/染めない"の判断もする相談サービス」
- カット：LINE画面、川崎さんからのメッセージ「今月は染めずに様子見ましょう」
- テキスト：「あなたの髪と頭皮を見ながら、月単位で一緒に決めます」

[55-65秒] 信頼
- ナレ：「無理に続けさせない。それが私のスタンスです」
- 川崎さん：「染める理由も、染めない理由も、両方あっていい」
- テキスト：「月880円、いつでも解約OK」

[65-68秒] CTA
- 大テキスト：「LINEで、今の髪の写真送ってみてください」
```

### キャプション
```
50代、染め続けるか、グレイヘアに移行するか
迷ってる人へ。

FOLLOWは"染める/染めない"の判断も
LINEで個別相談できるサービスです。

無理に続けさせない、それがスタンス。

▶ プロフから写真送って相談スタート

#グレイヘア #50代 #白髪 #セルフカラー #染めない選択
```

- CTR：1.8%
- CV率：6%（迷いが強い層は高めにCV）

## 台本③「分け目の白髪、月3回気にしてる人へ」（リタッチ専用・量産可能型）

### 狙い
- 30-40代の主力層を取りに行く
- FOLLOWの基本訴求の標準型として、毎月リフレッシュして配信し続ける汎用フォーマット

### 台本（65秒）

```
[0-3秒] 大テキスト：
「分け目の白髪、月3回は気になってませんか？」
→ スマホで分け目をチェックする女性

[3-15秒] 共感
- ナレ：「会議の朝、子どもの送り迎え、撮影の前」
- カット：日常シーンの連続
- テキスト：「気になる瞬間は、いつも"今すぐ"」

[15-30秒] 問題提起
- ナレ：「美容室は来月、セルフは怖い」
- ナレ：「市販の白髪染めは、強すぎてヒリヒリ」
- テキスト：「もっと"気軽な選択肢"があってほしい」

[30-50秒] 解決提示
- 川崎さん登場
- ナレ：「FOLLOWは、分け目だけリタッチする個別相談サービス」
- カット：LINE画面、塗布の場所を指で囲った写真
- ナレ：「あなたの分け目の写真を見て、塗る範囲だけ毎回提案します」
- テキスト：「月880円、いつでも解約OK、追加料金なし」

[50-60秒] 信頼
```

```
FOLLOWは"分け目だけリタッチ"の個別相談。

▶ プロフから分け目の写真送って相談スタート

#セルフカラー #白髪染め #リタッチ #分け目 #ジアミンフリー
```
