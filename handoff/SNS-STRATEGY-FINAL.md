## 3. 「FOLLOW誘導」のリズム（HEJからの流入設計）

HEJのスレッズで FOLLOW を紹介する頻度：**2日に1回**

実装パターン：
- 月・水・金・日 → FOLLOW誘導投稿（暗示的でも明示的でもOK）
- 火・木・土 → 業界話・川崎哲学・カラー知識（FOLLOW言及なし）

→ 「うざくない頻度」「自然な接点」を維持しつつ、月15回 FOLLOW を露出。

## 4. FOLLOW公式 Threads「1日3投稿 完全自動化」仕様

### 4-1. 投稿頻度
- **朝 7:30** / **昼 12:30** / **夜 21:00**（JST）

### 4-2. 自動化の流れ
```
A エージェントが毎晩 23:00 に翌日3投稿分を生成
  ↓
E エージェントが法務チェック（自動）
  ↓
合格したら DB（D1 sns_queue）に「scheduled」で保存
  ↓
Workers Cron が指定時刻に Threads API で投稿
  ↓
投稿後、SNS-LOG に記録、F が翌日のレポートに反映
```

### 4-3. 投稿内容の配分（1日3投稿 × 7日 = 21投稿/週）

```
朝 7:30 → 教育・実践（薬剤の使い方・頭皮ケア知識・季節対策）
昼 12:30 → 共感・コア訴求（気になるところだけ／月880円／FOLLOW案内）
夜 21:00 → 川崎さんの哲学・利用者の声・呼びかけ
```

### 4-4. E法務チェック自動化ルール
- 出力前に E-legal-checklist-prompt.md の全チェック項目を自動実行
- 「NG」「修正必要」が出たら投稿しない、ユーザーに通知
- 「OK」のみ自動投稿

### 4-5. 緊急停止フラグ
- 管理者LINEから「stop_auto_posting」コマンドで全停止
- 異常検知（同じ文言3回連続、API失敗）で自動停止
